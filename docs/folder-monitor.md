# 目录监控分享

在 `/115/folder-monitor` 选择主网盘中已有的文件夹，选中后自动保存。可以点「立即分享」处理当前内容，也可以开启自动监控。更换来源目录后需要重新开启自动监控。

## 文件如何分享

1. 读取监控目录的顶层条目，固定本批文件和子目录的 ID。目录为空时结束本次检查。单批最多处理 1000 个顶层条目。
2. 在本批主账号的根目录（CID 0）创建 `Cinema115-临时-xxxx`，将本批条目移入。监控目录本身留在原位，读取以后新增的顶层条目留给下一批。
3. 确认本批条目已到位，按这些 ID 创建分享，设置长期有效和提取码。分享打开后显示本批原有的文件和子目录。
4. 在最近记录中保存分享链接、文件所在目录及任务日志，释放本批占用。文件保留在 `Cinema115-临时-xxxx`，分享成功后无需清理。最近记录保留 20 次完成、失败或结束的任务，重试更新同一条记录。

目录配置绑定所选目录的主账号。主账号变化后须重新选目录。提交时固定本批账号和设置，执行中使用该次取得的凭据。Cookie 不写入批次、分享任务或日志。

## 自动监控和 STRM

- 自动监控默认关闭，检查间隔可选 5、10、30 或 60 分钟，默认 10 分钟。定时器到期后提交检查，执行器读取一次监控目录顶层。浏览器轮询只展示任务状态。
- 下载整理成功并释放执行占用后，会提前唤醒同一主账号已开启且空闲的配置。目录写入被整理等任务占用时，已提交任务约 5 秒后重试。关闭自动监控会停止提交下一批，已提交的任务继续处理。
- 分享完成后，已开启的配置立即检查下一批。目录为空时恢复所选检查间隔。目录读取、搬运或建链失败时，监控可能暂停，核对后可恢复。
- STRM 生成可选。配置播放地址和输出目录后，每批分享确认后会尝试提交公共 STRM 任务，从已有链接直接生成。生成结果和重试状态可以在「生成日志列表」查看。提交和生成失败时，监控分享的结果保留，下一批可继续检查。

STRM 输出目录可选媒体库子目录，也可用 `.` 表示媒体库根目录。留空可仅创建分享。

## 未完成的批次

- 搬运中断时，可以继续原批次，只处理尚未确认到位的条目。创建临时目录或分享结果不确定时，需要先人工核对，防止重复创建。
- 「核对残留」可以结束已确认没有临时目录的失败批次，也可以回收已确认归属且为空的临时目录。目录有文件或状态不明时保留现场。
- 「结束本次任务」归档现有分享和文件位置，解除批次占用并关闭自动监控。该操作保留网盘文件、已有分享和已生成的 STRM。如需重新处理临时目录中剩余的文件，可先移回监控目录。
- 升级前已经配置好长期分享的批次，后台可用原链接归档并释放占用。旧 STRM 任务的状态可在生成日志中查看。

## 接口和日志

- `POST /api/admin/p115/folder-monitors/:id/share` 提交或继续当前批次，返回 `accepted`、`taskId`、`monitorId` 和可能已有的 `generationTaskId`。旧 `/:id/scan` 使用同一入口。
- `PUT /api/admin/p115/folder-monitors/:id/schedule` 设置 `enabled` 和 `intervalSeconds`。
- `POST /api/admin/p115/folder-monitors/:id/recover` 核对残留，`POST /api/admin/p115/folder-monitors/:id/end` 结束批次。请求带当前 `taskId`，旧页面的操作不会结束新的任务。
- 目录分享的任务编号、状态和恢复点持久保存。日志轮转见[日志保存](logging.md)。
