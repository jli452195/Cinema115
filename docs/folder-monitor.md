# 目录自动分享日志

`/115/folder-monitor` 的处理过程统一进入 `/logs` 的 **STRM** 模块，来源为 **目录监控**。任务区的“查看本次日志”按完整任务编号精确筛选，包含所有等级，可取消筛选查看其他任务。

- 每次新检查生成独立任务编号；已有临时批次重试或重启恢复时沿用编号，并增加执行次数。
- INFO 记录触发方式、绑定账号、目录检查、临时目录创建、批量移动、分享设置、快照读取、STRM 和元数据生成统计、清理及分享复核。
- DEBUG 包含生成器的逐文件信息、快照等待次数等细节。
- WARNING / ERROR 记录失败阶段、当前执行耗时与临时目录是否已清理，不记录 Cookie、签名下载地址或请求头。
- “STRM 生成完成”与“整批处理完成”分开记录；清理后复核失败不会再提示“临时目录已保留”。

115 明确返回“正在生成文件快照”时，每隔 5 秒重新读取分享，单次快照读取与等待窗口最多 90 秒。登录失效、审核拒绝等其他错误不会按快照未就绪反复重试。每次请求均使用本次执行固定的账号 Cookie。

快照读取超时停在原阶段，生成前不会清理临时目录。再次触发处理会继续已有分享，不重复移动或创建分享；清理后复核失败只继续复核。账号凭据变化仍会阻止旧批次继续执行，不会回退到其他账号。

此版本仍使用现有内存日志缓冲区：所有模块合计最近 2000 条，后端重启后清空。任务编号和执行次数持久保存，但历史日志不会补录。
