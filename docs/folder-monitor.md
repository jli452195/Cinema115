# 目录分享

`/115/folder-monitor` 保留原地址，页面改名为“115 目录分享”。保存配置后不扫描网盘；用户在目录页或手动整理页点击“分享配置目录”才提交后台任务。整理任务排队、执行或状态读取失败时，整理页禁用分享按钮。

## 公共入口

- 复用 `frontend/src/components/DirectoryShareButton.vue`，传入 `token`；可传 `configurationId` 指定目录配置，`disabled` 和 `disabledReason` 控制上游操作未完成时的可用性。
- `useDirectoryShare.ts` 封装提交和状态读取；前端轮询只查询任务状态，不触发网盘扫描。
- `POST /api/admin/p115/folder-monitors/:id/share` 返回 `accepted`、`taskId`、`monitorId`、`generationTaskId`。重复点击关联同一目录任务，不重复创建批次。旧 `/:id/scan` 保留兼容。
- `/:id/schedule` 只接受关闭旧定时；开启返回配置错误。启动迁移清除旧 `enabled`、`intervalSeconds`、`nextScanAt`，保留已提交任务及临时目录。内部每 15 秒推进已提交任务，不发现新目录内容。

## 账号与生成设置

目录分享是“115 分享 STRM”的目录入口，复用其明确选择的账号和服务端保存的生成选项。目录配置仍保存 `accountId`。保存时必须提交选择目录所用的账号编号；如果分享 STRM 已切换账号，要求重新选择目录，不把旧目录绑定到新账号。

提交时固定账号编号、凭据摘要、账号版本和生成设置。Cookie 仅存在本次执行内存中，不写入批次、分享任务或日志。已提交任务不受后续设置变动影响；原凭据失效或变化时停止，不切换账号。

## 执行与恢复

1. 读取指定目录的当前顶层内容及文件清单，按分享 STRM 的扩展名、大小、递归规则检查视频。没有匹配视频时提示原因，不移动或创建分享。
2. 固定本次顶层编号和内容指纹，创建临时目录，按固定范围批量移动。后来进入的顶层内容留待下次点击。子目录内容在处理期间变化时停止清理。
3. 创建长期分享并保存恢复点；创建结果不确定时停止，避免重复分享。
4. 持久关联公共 `ShareTasks` 任务，以 `direct` 模式复用分享工作流、生成器、日志和审核重试，不把自己的分享再次转存。
5. 公共任务核验分享快照与本批范围、视频可读性，再生成。115 明确返回快照生成中时每隔 5 秒读取，单次最多 90 秒。快照仍未就绪或审核未通过时，沿用分享功能的审核重试策略；未启用重试时保留任务供手动继续。
6. 视频和元数据全部成功后，目录任务核验临时目录内容，再移入回收站并复核分享。公共 STRM 任务“成功”和目录整批“完成”是两个阶段。

排队任务重启后继续；中断的目录直接生成任务复用原请求重试；失败批次保留原分享和临时目录。未完成目录批次关联的分享任务不能被清理日志操作删除。旧版没有文件范围的搬运批次，恢复时只捕获一次剩余内容，不持续排空来源。

目录搬运日志和公共生成日志使用同一 `STRM-MON-…` 编号；公共任务同时出现在分享任务日志。环形日志总量仍为 2000 条，重启后文本日志清空，任务编号、状态和恢复点持久保存。
