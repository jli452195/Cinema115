# Emby 用户删除与未完成账号清理

入口：管理端「Emby 用户管理」的用户卡片底部「删除用户」，直接打开已带入用户的删除确认弹窗。页面底部「删除用户与未完成账号清理」保留未完成账号清理与原任务续办入口。

## 操作流程

1. 在普通用户或播放子账号卡片点击「删除用户」，自动预览删除影响，无需先打开编辑弹窗或重新选择用户。未完成注册及子账号创建也有独立清理入口。
2. 核对目标名称、Emby ID、子账号数量、个人网盘配置数量和播放占用。输入显示的用户名确认。删除所有者时必须明确勾选连同其子账号删除。
3. 服务端重新核验预览；身份、名称或子账号清单变化时要求重新预览。管理员身份禁止删除，普通用户接口无权调用删除接口。
4. 事务保存删除意图，阻止新的登录、发现导入、注册续办、子账号续办及媒体请求。正在执行的取链/秒传请求先结束，原任务显示等待；点击「继续原任务」恢复。
5. 先删除子账号，再删除所有者。禁用登录并读回确认后，调用 Emby 删除接口。确认用户列表不再包含原 ID，且原 ID 查询返回 404，才开始本地清理。超时、5xx、列表遗漏均不能直接判定成功。
6. 清除本人个人网盘配置及凭据、扫码会话、静态播放绑定和手动秒传目标配置；事务删除个人资料、播放业务记录、创建任务、个人追更关联与通知，以及对应用户和共享池容量记录。事务成功后更新内存。
7. 任务显示「已完成」。请求响应丢失或进程重启后仍可继续原任务；已确认的外部删除不重复执行。同名的新 Emby ID 不继承旧身份或权益。

删除开始后没有撤销按钮。外部服务不可达、本地保存失败时保留待清理任务及身份封锁；恢复连接或存储后继续。没有自动后台循环删除，管理员从同一任务明确续办。

## 保留与边界

- 不删除 115 实际文件、主账号、管理员共享池账号，也不按相同 UID 清除其他配置的凭据。
- 保留删除任务、操作者、时间及原身份的最小防重建记录，不保存密码或 Cookie。已使用邀请保持已使用；未完成注册被删除后邀请撤销。
- 保留按真实 115 UID 和文件 ID 归属的秒传资料、副本历史，以及诊断日志和既有备份；这些不占用户或子账号配额。个人凭据删除后不能继续作为新请求的来源。
- 已发出的 CDN 地址不保证立即失效；这里清理的是业务容量，不代表中断真实 CDN 连接。
- 如果外部创建已经发起但始终没有确认 ID，只能通过原随机保留名核查；查不到时保留待核查任务，不猜测同名账号、不直接释放名额或遗忘创建。
- Emby 删除接口负责上游用户及其用户数据。本服务不会直接修改 Emby 文件系统、插件数据或备份，无法保证第三方插件和备份没有历史记录。

## 验证记录（2026-10-05）

- 后端全量 `go test ./... -count=1 -timeout 180s` 通过；相关包 `go vet` 通过。
- 前端类型检查与构建通过。
- 删除回归覆盖级联顺序、禁止管理员/普通用户越权、预览过期、预览后新增子账号、删除响应丢失、超时保留、重启恢复、本地清理失败恢复、事务回滚、同名不同 ID、不重复删除、已删除身份不再发现和登录、个人凭据/容量/名额清理，以及保留其他用户和主网盘。
- 8 路同一删除任务并发提交，重复 20 轮通过，每轮外部删除一次。
- `TestMemberDeletionHTTPCanary`：真实管理端 HTTP 路由、鉴权、Emby HTTP 客户端及临时 SQLite；隔离上游模拟删除 503、已删除但响应 502，续办后完成，数据库完整性检查通过。
- 独立浏览器上下文挂载实际组件，验证管理员过滤、用户名确认、级联勾选、待确认提示、原任务续办、完成状态；另挂载整个用户管理页确认用户与任务首次加载互不阻塞。

本轮灰度为隔离故障注入及真实页面验证，没有在实际 Emby 上删除用户，没有部署或切换服务流量。当前 Windows 环境未执行 Go race detector。

## 用户卡片平铺交互验证

播放来源及子账号名额在卡片内直接编辑，填 0 停止新建；检查网盘常驻状态区并使用已保存配置。检查及状态刷新保留未保存草稿和原始冲突校验值。公共媒体权限说明移至页面，删除和保存分别显示。

独立浏览器上下文挂载实际用户管理页并模拟 API，验证检查保留草稿、原位保存、取消恢复、管理员无删除入口、卡片直接带入删除预览、用户名及级联确认、完成后关闭弹窗并移除卡片。窄窗口实际内宽 502px，无横向溢出。没有修改真实用户数据。
