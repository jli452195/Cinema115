# 动漫订阅

动漫订阅用于从 RSS 获取番剧资源，下载到 115 网盘，再按命名设置整理到目标目录。订阅、下载与整理在后台执行。

## 开始前准备

1. 按 [115 账号配置](../guide/accounts.md) 完成主账号登录。
2. 打开项目中的「动漫订阅」，进入右上角「设置」。
3. 在「下载与整理」中选择云下载暂存目录和整理目录。

两个目录都是主账号网盘内的云端目录，与 Docker 挂载的本地 `/strm` 目录用途不同。

## 添加订阅

1. 在选番页选择 AniBT、蜜柑或 AnimeGarden，通过日历、季度或搜索找到番剧。
2. 点击番剧卡片，确认作品与 Bangumi 篇章，选择字幕组和 RSS 来源。
3. 确认匹配规则、TMDB 命名资料、目标季与集号偏移。
4. 打开「预览」，检查资源标题、匹配情况和整理后的文件名。
5. 点击「保存」。新订阅保存后启用，由后台独立检查、下载和整理。

预览只用于检查结果，不会提交下载任务，也不是保存订阅的前置条件。

## 下载与整理流程

后台检查 RSS，选择符合规则且尚未处理的资源，为每条下载任务创建独立暂存子目录。115 离线完成后，按命名规则重命名并移到整理目录；成功后清理该任务的临时目录。

在「我的订阅」中点击卡片，可打开配置弹窗修改来源和规则，或在「下载记录」查看具体执行情况。离线完成与整理完成是两个不同阶段，排查时应以任务记录为准。

## 字幕组与匹配规则

主 RSS 和备用 RSS 分别保存自己的匹配、排除和集号规则，可以订阅多个字幕组版本。每行填写一条正则：全部匹配规则都满足才通过，任一排除规则命中即跳过。

正则默认区分大小写，需要忽略大小写时可加 `(?i)`。不确定规则是否正确时，先在预览中核对实际资源。

订阅不会因为后续发布了 v2、v3 就自动重新下载替换已有版本。

## 集号与命名

集号偏移用于把字幕组的发布编号对应到目标季，例如字幕组第 25 话需要命名为 `S02E01`，可选择目标季 `2`、偏移 `-24`。

TMDB 用于命名参考，其季集数不作为限制资源下载和整理的上限。修改命名偏移不改变缺集与齐集判断。

## 归档与继续订阅

「设置 → RSS 设置」可以调整更新检查间隔、齐集自动归档与长期停更归档。总集数默认参考 Bangumi 正片集数，未知或不准确时可在单部订阅中手动填写。

归档会停止 RSS 检查并保留配置与记录。需要继续追踪时可选择「继续订阅」；归档后添加并启用新字幕组，可使用「保存并继续订阅」。

「删除订阅」会清除相应本地配置与记录，保留 115 网盘文件。再次订阅可能重新下载，删除前请确认自己的需求。
