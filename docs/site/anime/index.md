# 动漫订阅

动漫订阅从 AniBT 等站点读取 RSS，按字幕组和规格筛选资源，下载到 115 主账号，再按 TMDB 命名方案整理到云端媒体目录。保存后由后台持续执行，关闭网页不影响已保存的订阅。

本教程用 **AniBT** 和《弹珠汽水瓶里的千岁同学》演示。截图中的季度、发布数量、目录和 TMDB 资料仅供说明，请按自己订阅的篇章核对。

## 开始前准备

1. 按 [115 账号配置](../guide/accounts.md) 配置明确的 **115 主账号**。动漫订阅不使用动态小号池。
2. 准备两个不同的主账号云端目录，分别用于下载暂存和整理后的媒体文件。
3. 确认项目能读取来源站和 TMDB 资料；无法识别目标时，可以手动关联 TMDB 作品。

### 设置下载与整理目录 {#storage-settings}

进入「动漫订阅 → 设置 → 下载与整理」。订阅配置窗口下方的「设置」也能打开同一份目录配置。

![动漫存储设置：即时保存、下载目录1、整理目录2和已有任务提示](/images/anime/anibt-storage.webp)

图中编号对应：

1. **所有订阅共用，选择目录后立即保存**。此处不是随订阅草稿一起保存。
2. **下载目录1**：115 离线暂存位置，每条资源会使用独立子目录。
3. **整理目录2**：视频与配对字幕完成命名后移入的位置。
4. 修改只影响之后新建的任务，已有任务沿用原账号和目录。

例如可以分别使用「动漫下载暂存」和「动漫媒体库」。两者都在 115 云端，必须分开；Docker 挂载的 /strm 本地路径不能填在这里。更换主账号后，需要重新核对并选择下载、整理目录。

## 添加订阅

### 1. 在 AniBT 找到番剧

进入「动漫订阅」，选择 **AniBT**，通过季度、星期或搜索定位番剧，再点击番剧卡片打开「新增订阅」。

![AniBT 选番页：站点、搜索、季度和设置入口](/images/anime/anibt-catalog.webp)

图中编号对应：

1. 站点选择，本文保持 AniBT。
2. 番剧名称搜索。
3. 季度切换，下方还可以按星期缩小范围。
4. 「设置」入口；旁边的「我的订阅」用于管理已保存的订阅。

选番页展示站点目录，「我的订阅」展示你保存的配置。卡片中的「暂无资源」是当前站点收录状态，不能据此判断整部作品是否已经发布完成。

### 2. 选择 AniBT 条目和字幕组 {#source-selection}

在「主 RSS」区域点击「选择资源」。来源选择器按三步进行：

1. **资源条目**：核对名称与篇章，避免把前一季或特别篇选进来。
2. **字幕组**：例如选择 LoliHouse，读取它的最近发布。
3. **资源规格**：依据实际标题选择匹配模板。

即使从 AniBT 选番页进入，也要检查来源选择器中的站点确实是 AniBT。已定位到条目时，选择器可能直接显示字幕组步骤。

![AniBT 资源规格：字幕组、最近发布、匹配模板与确认按钮](/images/anime/anibt-source.webp)

图中编号对应：

1. 当前字幕组、条目名称和 AniBT 条目编号。
2. 最近发布。可以展开其他样本，核对分辨率、编码和字幕类型。
3. 匹配模板。示例选择 1080p、内封、HEVC、10bit；「全部规格」会接收该组所有规格，同集不同规格可能分别保留。
4. 首次选择时点击「使用此来源」，返回订阅表单。重新打开已选来源时，此按钮显示为截图中的「更新来源规则」。

**这一步只更新表单草稿，尚未保存订阅。** 模板根据近期标题生成，样本数量不代表完整发布历史。返回表单后仍可编辑匹配与排除规则。

### 3. 核对命名、季和总集数

![AniBT 订阅基本配置：整理目标、来源、规则、偏移和保存](/images/anime/anibt-config.webp)

图中编号对应：

1. **整理目标、目标季、总集数**。作品或季不对时使用「更换目标」；总集数用于齐集判断。
2. **主 RSS**。核对站点、条目、字幕组。
3. **匹配与排除规则**。每行一条，匹配必须全部满足，排除任一命中就跳过。
4. **集数偏移／自定义**。默认集号正确时保持偏移 0。
5. **预览与保存**。预览可选，点击保存后新订阅才会启用。

截图中 TMDB 目标季显示 25 集，Bangumi 总集数为 13。这两个字段来自不同资料、用途不同：**目标季控制命名，总集数判断本篇章是否齐集**，需要根据实际篇章确认，不能直接互相照抄。

#### Bangumi 集数在哪里看 {#bangumi-episodes}

点击配置窗口右上角的 **Bangumi 集数**，可以打开当前 Bangumi 条目的正片编号列表：

![Bangumi 集数入口和逐集列表](/images/anime/anibt-bangumi.webp)

1. 「Bangumi 集数」入口位于新增或修改订阅窗口的右上角。
2. 弹出的「Bangumi 逐集列表」显示 Bangumi 原编号和收录总数，仅供参考。

这里适合用来核对“当前条目到底有多少正片集”和来源标题的编号起点。它不会自动把总集数或 TMDB 目标季改掉；需要调整时，仍在表单的「目标季」和「总集数」字段中手动确认。特别篇、剧场版或分篇章条目应先确认 Bangumi 条目是否对应当前 RSS。

如果字幕组使用连续编号，例如来源第 25 话要整理为 S02E01，应选择目标季 2、集数偏移 -24。详细示例见 [集号与命名](./rules-and-naming.md#episode-naming)。

### 4. 可选：查看匹配与重命名预览

点击底部「预览」，读取当前表单下的匹配结果和预计名称。

![AniBT 匹配与重命名预览：来源、筛选、说明和名称对照](/images/anime/anibt-preview.webp)

图中编号对应：

1. 当前来源、已读数量、符合数量、需确认数量，以及「重新预览」。
2. 显示筛选、整理根目录、「详细信息」和「说明」。
3. 展开后的说明，包含命名边界、读取窗口和预览有效期。
4. 表头：规则匹配、处理状态、RSS、字幕组、原标题、重命名和发布时间。

优先检查原标题的集号能否对应到重命名中的 SxxExx，然后查看被过滤或需确认的原因。长标题可以在表格内横向滚动；点击「详细信息」能看到更多编号、规格和路径信息。

::: tip 预览不会下载
查看预览只核对匹配与命名，也不是保存的前置条件。预览里的处理状态来自已保存记录；「尚未处理」不表示已经提交下载。
:::

AniBT 仅提供最近 100 条发布的读取窗口，预览可能只含其中一部分，不能保证补齐整部历史。截图中的 3 条是当次实际读到的样本，不是这部番剧总共只有 3 集。

### 5. 保存并查看执行结果

检查来源、目标季、总集数、规则和目录后点击「保存」。新订阅保存后启用，后台按设置检查、下载并整理；预览时浏览了哪些行，不决定后台下载哪些行。

进入「我的订阅」，点击对应卡片重新打开配置：

- 「基本」查看来源与整理进度。
- 「备用 RSS」管理其他字幕组版本。
- 「下载记录」查看每条任务的下载与整理阶段。

确认成功时要看 **已整理**；115「网盘已完成」只代表离线下载阶段结束。后续操作见 [订阅管理与故障排查](./management.md)。

如果保存回执不确定，使用「核对原保存请求」。关闭未保存的窗口时可以选择「放弃修改」，草稿不会生效。
