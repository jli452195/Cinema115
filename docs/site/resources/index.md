# 资源搜索与下载整理

从影视详情页找到种子后，可以先选择视频、校正季集、配好字幕，再交给 115 下载并整理。本教程使用《轻声密语》（TMDB 42407）的 Moozzi2 合集演示，适用于蜜柑和 Anime Garden 的「115 整理」入口。

推荐顺序：**搜索资源 → 勾选视频 → 确认季集与命名 → 查找字幕 → 提交 → 查看任务记录**。编号已经正确时，直接跳过批量编号；只有一个季时，也不必暂存。

想跟着完整案例操作，可以查看 [《妹妹公主》两季 BDRip 实例](./sister-princess.md)：从 108 个视频中选择两季正片，分季暂存并匹配 39 个字幕。

::: tip 截图说明
下图来自实际浏览器操作，蓝色数字对应正文说明；私人目录已遮挡。搜索结果会随上游站点变化，文件名以你当前的公共命名模板预览为准。截图演示停在提交之前。
:::

## 准备与搜索入口 {#search}

先在 [115 助手](../guide/accounts.md) 配好**主账号**，并在「115 网盘 → 115 转存」配置磁力下载目录。进入作品详情页，打开蜜柑或 Anime Garden 搜索；找不到时，可以切换中文标题、原名，或手动修改搜索词。

![蜜柑搜索中的 Moozzi2 合集，标出资源标题、115 整理和 115 云下载](/images/resources/resource-search.webp)

图中 **①** 是本次演示的 Moozzi2 资源。先核对作品、版本、分辨率和容量，必要时查看原帖，再选择操作：

| 入口 | 适合的需求 |
| --- | --- |
| **② 115 整理** | 选择需要的视频、校正季集、关联字幕，下载后按公共模板重命名并移动。本文使用这个入口。 |
| **③ 115 云下载** | 直接把资源交给 115，保存到已配置的下载目录。不会进入本文的选片、编号和配字幕流程。 |
| 整理弹窗内的 **115 分享 STRM** | 在下载、整理后继续生成分享 STRM；需提前配置分享功能，进度仍在下载整理记录中查看。 |

## 选择视频与整理目录 {#select-videos}

点击「115 整理」后等待文件清单加载。合集需要自己勾选视频；不要仅凭资源标题中的 `TV + SP`，就把所有文件都当成正片。

![下载并整理弹窗，标出目录、字幕入口、批量编号、文件预览和提交按钮](/images/resources/organize-preview.webp)

本例读取到 **25 个视频**：根目录有 13 集正片，`EXTRA` 下另有 12 个附加视频。演示只整理正片：勾选根目录后取消 `EXTRA`，确认顶部显示「已勾选 13 个」。确定整个 `EXTRA` 都不需要时，也可以点击该目录右侧的「本次排除」，把它从待处理列表隐藏。

按图中顺序核对：

1. **① 选择目录**：选择本次正片要放入的主账号目录。弹窗选目录不会立即修改网盘文件，也不会修改全局整理配置；成功创建任务后会记住下载整理的目标目录。
2. **③ 批量编号**：本例正片已经是第 1 季第 1—13 集，无需调整。需要改号时参考[下一节](#numbering)。
3. **④ 文件预览**：逐行查看原文件名、目标季集及「整理后」名称。图中 `Whispered Words.S01E01.1080p.mkv` 来自当前公共模板，你的模板可能使用中文标题或包含不同字段。
4. **② 查找字幕**：季集确定后再配字幕；配好后，视频下方会出现「外部字幕」供展开核对。
5. **⑤ 提交区域**：检查视频、字幕数量和目标位置，最后才选择下载整理或分享 STRM。

### 本次排除与暂存分别做什么 {#selection-actions}

![标出 EXTRA 目录的本次排除按钮，以及批量编号栏右侧的暂存这 13 项按钮](/images/resources/selection-actions.webp)

**① 本次排除**：用于本次完全不想整理的目录，例如本例的 `EXTRA`。点击后，会取消该目录及所有下级文件的勾选，并隐藏整个目录；以后勾选上级目录，也不会把它重新选进来。排错了，在文件列表上方展开「查看已排除目录」，点击「恢复」；**恢复后仍未勾选，需要自己重新选择**。排除只在本次弹窗有效，点击时不会删除网盘文件，也不会减少整条磁力的下载量；提交后剩余文件的清理见下方说明。

**取消勾选**适合暂时不选、还想留在列表里查看的文件。与排除不同，它不会隐藏目录，重新勾选上级目录时，这些文件仍可能一起选中。

**② 暂存这 N 项**：用于已经确认好、准备和其他文件一起整理的视频。点击后，当前勾选且没有校验问题的视频会移到上方「已暂存」确认区，保留季集与字幕关联；有问题的条目留在待处理区。接着可以选下一季、继续批量编号，已暂存项不会跟着改号。需要调整时点击暂存分组里的「退回编辑」，最终提交会包含**已暂存项和当前勾选项**。

只有一个季、一次就能确认完时，直接提交即可，不必先暂存。**暂存不会启动下载，也不是持久草稿；关闭弹窗后会丢失。**多季操作见[分季处理示例](#multi-season)。按钮显示「暂存这 0 项」时，先勾选视频并等待命名预览加载；存在问题的条目应先修正。

::: warning 勾选决定整理范围
115 按**整条磁力**下载，勾选视频不等于只下载这些文件。本例这类读取完整清单的合集，全部所选文件整理成功后，临时目录中的未选、排除及其他残留文件会一并回收，包括未匹配的种子内字幕。需要的正片、特别篇和字幕应在提交前确认。按标题直接识别的单集若自动排除了片头、片尾或 SAMPLE 等附加视频，会保留下载目录。
:::

## 应用偏移与连续编号 {#numbering}

两种工具都只修改**待处理区中当前勾选的视频**，已经暂存的视频不受影响。先选择目标季，再填写起始集，点击对应按钮后核对每行预览；仅切换「目标季」不会批量修改文件。

**应用偏移**适合发布编号可靠、只是与 TMDB 相差固定集数的情况。计算方式是：**目标集 = 原始识别的发布集 − 发布起始集 + 目标起始集**，会保留缺号和连集跨度。

**连续编号**从目标起始集开始，按文件列表中所选项的顺序重新编号，**不是勾选先后**。适合原编号不能使用、但你已经确认播放顺序的情况；它会把缺号排成连续编号。

### 用同一组文件对比

假设第二季从发布集 **25** 开始，当前只有 `25、27、28` 三个文件。设置目标季为第 2 季，发布集 `25` 对应目标集 `1`：

| 原始发布集 | 应用偏移 | 连续编号 |
| --- | --- | --- |
| 25 | S02E01 | S02E01 |
| 27 | S02E03 | S02E02 |
| 28 | S02E04 | S02E03 |

这里实际缺了发布集 26，应该用**应用偏移**，让目标第 2 集继续空缺。连续编号会把后面的集数提前，适合“顺序确定、原编号不可用”的场景，不能用来补齐缺集。

- 偏移始终参考最初识别的发布集，不会在上一次改好的目标集上反复叠加。改错可点击「撤销」，撤回上次批量编号，或直接修改行内季集。
- 没识别出发布集的文件会被偏移跳过。少量文件可手填；使用连续编号前先确认顺序，并填写有效的起始集。
- 连集文件会保留占用集数。例如一个文件覆盖 `01—02`，连续编号时下一个文件从第 3 集开始。
- 特别篇应按 TMDB 的特别篇集号核对，目标季选「特别篇」（季 0）。`NCOP`、`NCED`、PV 不应仅凭文件夹里有 `SP` 就直接编入特别篇。

### 多季合集：分季处理，再一起提交 {#multi-season}

带截图的完整操作见 [《妹妹公主》第一季、第二季实例](./sister-princess.md#season-one)。

1. 只勾选第一季文件，确认季集和命名，点击「暂存这 N 项」。
2. 勾选下一季文件，设置目标季，应用偏移或连续编号，再核对预览。
3. 重复处理其余季。暂存完成后，从各季分组里的「查找字幕」分别匹配，每季点击「使用所选字幕」返回，再处理下一季，最后一起提交。

暂存项会移到上方确认区，和当前勾选项一起整理；需要调整时可「退回编辑」。**暂存仅保留在当前弹窗，关闭会丢失，不是持久草稿，也不会启动下载。**

## 查找字幕与核对对应关系 {#subtitles}

视频季集确认后，单季可以使用顶部「查找字幕」。**多季合集推荐从暂存分组里逐季查找**：先点击第一季右侧的「查找字幕」，匹配后点击「使用所选字幕」返回整理弹窗，再点击第二季右侧的入口。这样每次只匹配该季视频，后一次确认也会保留其他季已加入的字幕。

顶部入口会同时包含已暂存和当前勾选的视频；多个季都有第 01 集、字幕又没有季号时，可能需要额外指定「字幕所属季」。分季操作示例见[第一季确认后，再查找第二季](./sister-princess.md#subtitles)。

### 搜索或导入

![字幕搜索弹窗，标出搜索词、导入字幕和 Moozzi2 字幕结果](/images/resources/subtitle-search.webp)

图中 **①** 可以修改作品名，**②** 可以导入本地字幕，**③** 是与本例资源版本相近的射手网结果。优先对照发布组、BD／WEB 版本和文件名，再点击读取。

动漫作品会搜索字幕库，并查询已配置的射手网。没有结果时，可以尝试原名、英文名，或者导入字幕文件、ZIP／RAR／7z 压缩包；支持拖入。

支持 `.ass`、`.ssa`、`.srt`、`.vtt`、`.idx`、`.sub`。单个字幕上限 16 MiB，每次最多选择 100 个字幕，所选字幕合计不超过 64 MiB；导入压缩包也会检查解压后的字幕数量和大小，导入的原文件合计不能超过 64 MiB。IDX 需要同时选择配套 SUB。

### 对应视频、语言与目标名称

![字幕匹配列表，标出对应视频与语言、整理后名称及使用所选字幕](/images/resources/subtitle-mapping.webp)

本例读取到 13 个字幕，全部匹配到对应视频。按图核对：

1. **① 对应视频、语言和版本**：字幕第 01 集应对应视频第 01 集；自动匹配有歧义时，手动选择视频。图中语言为「未指定」，需要根据字幕实际内容选择；不要只凭搜索结果猜测。需要区分同语言的不同字幕时，可填写版本。
2. **② 整理后名称**：核对字幕是否跟随对应视频的目标名称。语言和版本会影响字幕后缀；目标名称重复时，应调整或取消其中一项。
3. **③ 使用所选字幕**：确认后返回整理弹窗，展开视频下方的「外部字幕」再次查看。此时只是把字幕加入本次计划，最终提交下载整理后才会上传、整理。

对于本例这样的剧集，字幕库默认勾选已匹配的简中字幕；本地和射手网字幕会默认勾选匹配成功的条目。电影字幕需要自己勾选。**最终以复选框和底部已选数量为准**，未匹配的条目需要手动指定视频后再选择。

::: tip 多季与语言筛选
如果视频跨多个季，而字幕只有集号、没有季号，先选择「字幕所属季」。切换所属季只尝试匹配未关联项，已有对应关系仍需自己核对。明确的 `S02E01` 可按季集匹配，原发布编号也会辅助对应。

「语言」筛选只改变显示范围，不会自动取消其他语言的已选字幕；「选择当前已匹配项」选择当前筛选范围内已匹配的条目。
:::

自动匹配确认的是文件与集数的对应关系，**不会验证字幕时间轴**。同一集的 BD、WEB 或不同剪辑版本仍可能存在时间差，应选择与视频版本相符的字幕。

## 提交与进度追踪 {#tracking}

提交前核对视频数量、目标目录、季集、目标文件名和字幕选择，再根据用途选择：

- **下载并自动整理**：下载到临时目录，确认实际文件后重命名、移动到所选整理目录，并处理关联字幕和清理。
- **115 分享 STRM**：使用主账号根目录下独立的 `Cinema115-*` 任务文件夹，下载、整理后继续生成分享 STRM，不使用普通整理目标目录。分享设置沿用「115 分享 STRM」页面。

若服务端最终命名有变化，页面会更新预览并要求再次确认；看到冲突或「待处理」提示时，先修正对应文件。明确的单集资源可能按标题直接预览，实际扩展名和关联字幕会在下载后确认；合集及不明确的资源需要读取文件清单。

任务创建后，当前 Toast 会更新下载、整理及 STRM 状态，关闭搜索或整理弹窗后任务仍会继续。需要回看结果时，进入 **「115 网盘 → 下载整理」**，在任务记录里查看同一批次各资源的进度。

| 状态或问题 | 怎么处理 |
| --- | --- |
| 下载还没完成 | 在记录中查看下载阶段，避免反复提交同一资源。 |
| 部分失败或待核对 | 打开详情，按提示核对；出现「检查并继续」时沿用原任务恢复，保留已完成进度。 |
| 文件已整理，但显示待清理 | 使用「重试清理」，只继续回收本任务临时目录。 |
| 分享 STRM 失败 | 有「重试 STRM」时只重试该阶段，不必重新下载、整理。 |
| 创建结果未确认 | 使用「确认任务状态」读取同一任务，或先查看任务记录。 |

需要长期自动追更时，继续阅读 [动漫订阅](../anime/index.md)；订阅中的发布集映射见 [匹配规则与命名](../anime/rules-and-naming.md#episode-naming)。
