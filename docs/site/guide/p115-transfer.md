# 115 转存与功能速选

想把资源存进网盘，先读本页；想生成供 Emby 使用的 `.strm` 文件，继续看 [115 STRM 媒体库入门](./p115-strm.md)。开始前先在「115 网盘 → 115 助手」[创建并登录主账号](./accounts.md)。

截图使用当前界面与示例配置，蓝色数字对应下文；未向 115 提交真实转存。图片可点击放大。

## 我应该点哪个入口 {#choose}

打开管理端「115 网盘」，按手里的资源和目标选择：

| 我想做什么 | 使用入口 | 完成后得到什么 |
| --- | --- | --- |
| 把搜索到的 115 分享存进自己的网盘 | 搜索结果中的 **115 转存**；目录在「115 转存 → 115 链接转存」配置 | 所选主账号目录中的资源，保留原分享结构。 |
| 把磁力或 ED2K 下载到网盘 | 「115 转存 → 磁力/ED2K 转存」，或搜索结果中的 **115 云下载** | 下载目录中的文件；不进入选片、编号和配字幕流程。 |
| 下载前选正片、核对季集、匹配字幕 | 搜索结果中的 **115 整理** | 按预览名称整理后的文件；到「下载整理」查看任务。见[图解教程](../resources/index.md)。 |
| 从分享链接生成 STRM | **115分享STRM** | 本地 `.strm`，可选直接生成或转存再分享。见 [分享 STRM](./p115-strm.md#share)。 |
| 网盘已有文件，持续生成本地 STRM | **115网盘STRM** | 来源网盘目录与本地输出目录的映射。见 [网盘 STRM](./p115-strm.md#drive)。 |
| 监控网盘目录，自动创建分享再生成 STRM | **115 监控分享** | 自动创建的分享和本地 STRM；与直接映射网盘文件的「115网盘STRM」不同。 |

「115 助手」负责账号连接，不是资源转存入口。以上普通功能统一使用主账号；管理员小号和用户个人网盘的用途见[账号配置](./accounts.md)。CloudDrive2 使用独立的存储入口和文件标识，不能把其文件标识当作这里的 115 目录 ID。

## 第一步：配置分享接收目录 {#targets}

从「115 网盘」点击 **115 转存**，进入后的页面标题是「115 云转存」。选择 **115 链接转存** 页签。

![115 链接转存的目录配置，标出页签、新增目录和已配置的接收目录](/images/115/transfer-targets.webp)

图中 **1** 是「115 链接转存」页签。点击 **2 新增目录**，填写「配置名称」（如「动画」），点击 **选择目录** 选好主账号的接收位置，再点击 **保存目录**。保存后，列表应出现 **3** 这样的配置名称和路径。

这一页只配置接收目录，转存资源在搜索结果中操作。网页使用无需分配 Bot；需要让 Telegram Bot 接收分享时，再到「Telegram 配置 → Bot 配置」分配对应目录功能。

同一个 Bot 可以同时分配多个 **115 链接转存** 目录和 **115 分享 STRM**。私聊直接发送 115 分享链接；只有一个适用目标且可用时直接处理，多个目标时在同一条消息里选择 **转存到网盘 · 接收目录** 或 **生成分享 STRM · 输出目录**。选择前不创建任务，暂不可用的已分配目标不会被排除后自动改投其他用途。

分享 STRM 使用「115分享STRM」当前保存的单个输出目录，以及直接生成或转存再分享策略；这里不额外配置输出目录。选择消息 10 分钟内有效，仅原发送者可用，可取消，失效后重新发送。115 分享与磁力或 ED2K 混发仍整批拒绝。

## 第二步：搜索后点击转存 {#search-transfer}

进入影视详情页，打开已配置的资源搜索来源。找到提供 115 分享的结果后，先看搜索区域的 **转存到**，再点资源上的 **115 转存**。

![搜索结果中的转存目录选择和 115 转存按钮](/images/115/transfer-search.webp)

图中 **1** 先选接收目录，**2 115 转存** 保存资源。旁边的 **3 分享 STRM** 用于生成本地 STRM，原样存网盘时点 **2**。

| 目录配置情况 | 怎么操作 |
| --- | --- |
| 没有可用目录 | 点击 **配置转存目录**，先按上一步保存；此时转存按钮不可用。 |
| 只有一个目录 | 自动使用它，直接点击资源的 **115 转存**。 |
| 有两个或更多目录 | 先在 **转存到** 下拉框选择一个；后续资源复用这个选择，浏览器会记住。 |

点击后会先获取该资源的分享链接：只有一个分享时直接提交；有多个分享时，在展开的下拉框中选择具体分享，**选中即提交**。

这里只接收分享资源，保留原有文件和目录结构。它不会额外创建 `Cinema115-*` 临时工作目录，也不会自动生成 STRM。想把已转存的文件加入媒体库，可继续配置[网盘 STRM](./p115-strm.md#drive)。

## 第三步：等待结果，再检查目标目录 {#result}

提交后先等按钮或提示返回结果，再关闭搜索弹窗。

| 显示状态 | 含义与下一步 |
| --- | --- |
| 获取链接… | 正在读取资源分享地址，等待即可。 |
| 转存中… | 正在提交给 115，避免重复点击。 |
| 已转存 | 115 已接受转存请求；打开所选目标目录确认文件，文件尚未到齐时稍后刷新。 |
| 待核对 | 请求结果不确定，先检查目标目录，避免重复转存；不要把它当成明确失败。 |
| 重试转存 | 操作明确失败；根据错误提示修正后重试。 |

普通分享转存没有独立的持久后台任务记录。关闭弹窗可能中断当前请求，已经被 115 接受的操作不会撤回；如果关闭时还没看到结果，先到目标目录核对。页面内的转存状态也不等于刷新后可恢复的历史记录。

## 只有磁力或 ED2K 时 {#magnet}

1. 打开「115 转存 → **磁力/ED2K 转存**」。
2. 在「下载目录」点击 **选择目录**，确认保存位置。
3. 粘贴链接，点击 **开始云下载**，根据返回提示到 115 查看任务和文件。

搜索结果中的 **115 云下载** 使用已配置的下载目录。若还要选择合集中的正片、调整编号或配字幕，使用 **115 整理**，按[资源搜索与下载整理](../resources/index.md)操作。

也可在「Telegram 配置 → Bot 配置」分配目录，配置允许的聊天 ID 并启用 Bot，然后在私聊直接发送链接：

- 纯 ED2K 按已分配的云下载和 ED2K STRM 目录处理。仅一个适用目标且可用时自动处理；多个目标先选择「普通转存 · 目录名」或「生成 STRM · 目录名」，选择前不创建任务。目标未就绪时提示配置，不自动改用别的目录。
- 磁力只用于云下载，可与 ED2K 混发，整批下载到同一个所选云下载目录。即使分配了 STRM 也不提供生成选项；只有 STRM 功能时整批不提交。
- 115 分享请单独发送；与磁力或 ED2K 混发时整批拒绝，不会只处理其中一部分。

选择消息 10 分钟内有效，仅原发送者可用，可取消；失效后重新发送。也可用 `/cloud` 限定云下载、`/ed2kstrm` 限定 STRM；显式命令同样整批校验，STRM 消息含磁力或云下载消息含分享时不会提交。

## 换账号或找不到目录时 {#directory-help}

- 接收目录与主账号归属绑定。更换主账号后，回目录配置重新选择并保存，不沿用旧账号的目录 ID。
- 删除接收目录配置只移除配置，不删除网盘文件。
- 普通分享的接收目录可自行选择；[转存再分享](./p115-strm.md#reshare)使用的临时工作目录固定在主账号根目录，两者用途不同。
