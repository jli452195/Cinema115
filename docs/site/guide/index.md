# 开始使用

Cinema115 提供 115 分享 STRM、云下载与整理、动漫 RSS 订阅，以及 Emby 原文件直链播放等功能。日常操作通过网页完成，NAS 部署只需要一个 Docker 容器。

## 首次安装

1. 按照 [Docker 部署](./installation.md) 启动服务，确认能打开管理页面。
2. 使用 Compose 中设置的管理员账号登录。
3. 在 [115 助手](./accounts.md) 中配置主账号，再设置需要使用的功能目录。

## 按需要配置

| 需求 | 配置入口与准备事项 |
| --- | --- |
| 从 115 分享生成 STRM | 进入「115 网盘 → 115分享STRM」，设置本地生成目录和播放地址。 |
| 云下载并整理 | 先配置主账号与云端目录，再提交资源并确认整理预览。 |
| [动漫 RSS 订阅](../anime/index.md) | 选择来源、字幕组和目录，确认命名映射后开始订阅。 |
| Emby 原文件直链播放 | 配置 Emby 302 反代，并让播放器通过反代入口连接 Emby。 |

媒体库和播放器需要能够访问 STRM 中填写的 Cinema115 地址。不同功能的目录用途不同，请在对应页面确认后保存。

## 日常维护

升级前阅读 [更新与备份](./upgrade.md)。遇到访问、权限或路径问题，可以先查看 [常见问题](../faq/index.md)。

文档与项目代码在同一仓库维护。发现步骤与当前界面不一致，可以使用页面底部的编辑链接提交修正，或在 [GitHub Issues](https://github.com/jli452195/Cinema115/issues) 反馈。
