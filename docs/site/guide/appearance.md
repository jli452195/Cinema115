# 深浅主题与界面预览

Cinema115 提供浅色、深色和跟随系统三种外观设置。下面的截图来自当前项目界面，同一页面的两种主题使用相同的筛选、位置和视口，方便对照。

## 在项目中切换主题

电脑端可以直接点击顶栏的太阳或月亮按钮，在浅色和深色之间切换。旁边的显示器按钮用于**跟随系统**；选中时显示蓝色，系统外观变化后页面会同步更新。

手机端先打开顶栏的「更多功能」，在账户菜单中找到主题按钮和「跟随系统」。登录页右上方也提供相同入口。

手动选择浅色或深色后，页面不再跟随系统；再次点击显示器按钮即可恢复。设置保存在当前浏览器中，刷新后仍然生效。

## 体验切换动效

<AppearanceDemo />

点击上方按钮，或使用文档导航中的主题开关，即可体验与项目一致的圆形软边动效：浅色转深色时，深色从点击位置向外展开；深色转浅色时，深色向点击位置收拢。页面和当前轮播截图共用同一个蒙版，蒙版扫过到哪里，截图就在哪里切换主题，不会另起一层截图动画。转场约 400 毫秒，键盘激活时以按钮中心为起点。

文档首页的预览图和放大图会一起切换到对应主题。文档与项目分别保存自己的外观偏好。

如果系统启用了「减少动态效果」，或浏览器不支持 View Transitions，主题会直接切换。
