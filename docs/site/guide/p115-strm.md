# 115 STRM 媒体库入门

STRM 是保存播放地址的小文件，视频仍在网盘。Cinema115 只提供原文件直链播放，不转码或重新封装。首次使用先[登录主账号](./accounts.md)，再按资源位置选择：

| 资源在哪里 | 使用功能 |
| --- | --- |
| 手里有 115 分享链接 | [115分享STRM](#share)：直接使用原分享，或转存再分享后生成。 |
| 文件已在主账号网盘目录中 | [115网盘STRM](#drive)：建立云端目录到本地目录的映射。 |

只是想把分享存进网盘时，按 [115 转存教程](./p115-transfer.md)操作即可。

截图使用当前界面与示例配置，蓝色数字对应下文；未向 115 提交真实生成或扫描任务。图片可点击放大。

## 分享链接生成 STRM {#share}

### 1. 保存基础设置 {#share-settings}

进入「115 网盘 → **115分享STRM**」，默认打开 **基础设置**。第一次主要检查这几项：

| 设置 | 怎么填 |
| --- | --- |
| STRM 播放地址 | Emby 和播放器能访问的 Cinema115 地址，例如 `http://NAS_IP:8115`，不是 115 网站地址。 |
| 分享路径 | 默认 `/` 处理整个分享；只需要某一目录时填 `/电影` 这样的分享内路径，包含其子目录。 |
| 视频后缀、最小文件大小 | 决定哪些视频生成 STRM；小体积正片被跳过时检查最小大小。 |
| 元数据后缀 | 需要随分享下载的字幕等原文件后缀；留空则不下载。 |
| STRM 输出目录 | 使用 **添加目录** 选择本地目录，供生成时使用。 |

修改后点击 **保存设置**。本地目录是运行 Cinema115 的容器内路径，例如 `/strm/剧集`；若挂载为 `/vol1/媒体库:/strm`，它对应 NAS 的 `/vol1/媒体库/剧集`，不是 115 网盘里的目录。

### 2. 核对链接、模式和输出位置 {#generate}

切换到 **生成STRM**，按图核对：

![分享 STRM 生成表单，标出模式、链接和开始生成，输出位置及预览按钮在同一区域](/images/115/share-generate.webp)

1. **图中 1 选模式**：选择「直接生成」或「转存再分享」。
2. **图中 2 填链接**：包含提取码的分享文本可直接粘贴；识别不全时使用 **补充提取码** 或 **修改提取码**。
3. **核对输出，点击图中 3 开始生成**：确认「STRM 输出目录」，需要时点击 **更改**；提交后等待成功提示。

需要先确认内容时，点击 **预览文件**；只生成某个子目录时，打开它并点击 **设为生成起始目录**。

**直接生成**适用于自己或他人的可读分享，不先转存，STRM 继续依赖原分享的有效性。预览不是必须步骤，已经确认分享内容时可以直接生成。

### 转存再分享会做什么 {#reshare}

需要由自己的主账号创建分享时，选择 **转存再分享**。对于他人分享，流程是：

**主账号根目录自动创建 `Cinema115-*` 工作目录 → 接收并核对文件 → 创建自己的长期分享 → 生成 STRM → 成功后将工作目录移入回收站。**

无需选择临时目录的父目录；生成失败时保留工作目录，先根据生成日志检查。本人创建且可读的分享会直接复用原链接，不额外转存。新分享虽然设为长期，仍可能受账号状态、手动取消和 115 审核影响。

普通 [115 转存](./p115-transfer.md#targets)是把资源长期放到自己选择的接收目录；这里的工作目录用于生成任务，成功后会清理，不能当作资源归档目录。

### 3. 查看结果与生成日志 {#share-result}

生成完成后，检查 **STRM 数量、已保存到的本地目录、元数据失败数**。转存再分享还应查看 **自己的分享链接** 和临时目录清理结果，然后让 Emby 扫描对应的本地 STRM 目录。

已经提交成功的生成任务由后台执行，关闭页面不会取消。回到 **115分享STRM → 生成日志** 可查成功、失败和审核重试记录；需要中止当前生成时使用 **停止任务**。

| 遇到的情况 | 先做什么 |
| --- | --- |
| 生成数量为 0 或少于预期 | 检查分享路径、视频后缀、最小文件大小和实际分享内容。 |
| 分享审核中 | 查看日志原因；需要等待后自动重试时，在基础设置启用 **分享审核中自动重试** 并保存。 |
| STRM 已生成，字幕等元数据部分失败 | 根据结果和日志核对缺失附件，不把视频生成成功等同于附件全部成功。 |
| 转存再分享失败且留下工作目录 | 先查日志和已有新分享，核对网盘后再处理，避免重复转存或误删。 |
| Emby 找到文件却不能播放 | 先按[播放排查](../faq/index.md#strm-playback)确认地址、账号和分享状态。生成成功不代表已完成播放验证。 |

## 网盘已有文件生成 STRM {#drive}

进入「115 网盘 → **115网盘STRM**」，将一个主网盘子目录对应到一个本地输出目录。

### 1. 保存基础设置

先填写 **STRM 播放地址**，检查视频后缀、元数据后缀和最小文件大小，点击 **保存设置**。地址和本地路径的含义与上面的[分享设置](#share-settings)相同，但两页的配置需要分别保存。

### 2. 添加来源与本地目录 {#drive-directory}

点击 **添加目录**，按图填写并核对：

![网盘 STRM 新增目录，标出网盘来源、本地输出与保存入口](/images/115/drive-strm-directory.webp)

先填写便于区分的目录名称，再按图核对：

1. **图中 1 配对两个目录**：左侧「主网盘来源」选择网盘中的具体子目录，例如 `/动画`，不能选网盘根目录；右侧「本地输出」选择本地目录，图中显示「动画」、实际为 `/strm/动画`，用于存放 STRM 和附件。
2. **图中 2 设置自动任务**：按需要设置增量核对、全量扫描周期；上方「自动监控」控制该目录是否参与自动调度。
3. **图中 3 保存目录**：确认来源与本地输出没有选反，再保存。

新增目录保存后会安排首次完整扫描，无需紧接着再点一次扫描。稍后在目录卡片查看状态、生成数量和附件情况；STRM 会先生成，字幕、图片等附件继续在后台补齐。

### 3. 日常同步与停止 {#drive-maintenance}

| 操作 | 作用 |
| --- | --- |
| 检查更新 | 根据生活事件处理变更；目录需开启监控。 |
| 完整扫描补齐 | 重新读取来源，核对并补齐本地输出。 |
| 编辑目录与自动任务 | 调整来源、本地目录或周期。增量核对和全量扫描按每个目录独立配置；生活事件检查间隔在基础设置中共用。 |
| 暂停监控 | 停止该目录后续自动调度，当前已接受任务仍继续。 |
| 停止本次 | 停止当前扫描或附件补齐，已生成文件保留。 |
| 删除目录配置 | 删除映射配置和索引，保留已有本地文件及网盘文件。 |

云端删除文件不会自动删除本地已生成文件。同一文件改名或移动时，新输出生成成功后会清理旧输出；不要把手工修改的 STRM 当作独立备份。换主账号后，需要重新选择来源目录。

## 可选：分享 STRM 的 Telegram 通知 {#telegram}

网页手动生成无需配置 Bot。需要分享 STRM 完成通知时：

1. 进入「Telegram 配置 → **Bot 配置**」，新增或编辑 Bot，保存 Token 和 **独立通知聊天 ID**。
2. 把 **115 分享 STRM** 功能卡片拖入该 Bot，或直接从卡片选择 Bot 分配；编辑 Bot 时打开 **启用 Bot 配置** 并保存。
3. 私聊先与 Bot 发起会话；群聊需允许它发言。需要直接向 Bot 发送分享链接时，另外配置 **允许的聊天 ID**。

分享页面的 **管理与分配** 可进入同一配置页。通知失败不等于生成失败，任务结果仍以 **生成日志** 和实际文件为准。

同一 Bot 可同时分配 **115 分享 STRM** 和分享转存目录。私聊直接发送分享链接；多个适用目标时，一次选择生成分享 STRM 或转存到指定网盘目录，选择前不创建任务。生成沿用本页保存的单输出目录和直接生成/转存再分享设置。
