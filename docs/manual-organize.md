# 115 手动整理

入口：**115 网盘 → 手动整理**（`/115/manual-organize`）。用于手动修正自动识别失败的单部电影或剧集。需要已登录的 115 账号，以及后端已有的 `TMDB_API_KEY` 配置。

## 使用流程

1. 明确选择此功能使用的 115 账号，再选择来源和目标目录。配置会单独保存；切换账号后需要重新选择目录。
2. 从来源目录选择一个视频或文件夹。文件夹会展开内部视频，可进入子目录，也可取消勾选样片、预告等文件。
3. 搜索 TMDB 片名并选择作品，或输入 TMDB ID、作品链接。仅输入 ID 时先选择电影或剧集。
4. 电影可修改版本标记；剧集可逐项修改季、集、结束集，或按当前文件顺序连续编号。连续编号采用文件路径自然排序，需要人工确认与内容一致。单集的结束集留空。
5. 点击“预览整理结果”，检查每个文件的原路径与目标路径。处理冲突后重新预览，再确认执行。

命名示例：

```text
目标目录/
  星际穿越 (2014) {tmdb-157336}/
    星际穿越 (2014) - 1080p WEB-DL.mkv
    星际穿越 (2014) - 1080p WEB-DL.zh-CN.srt
  某部剧 (2024) {tmdb-123}/
    Season 01/
      某部剧 - S01E01.mkv
      某部剧 - S01E02-E03.mkv
```

不增加国家、类型等分类，也不生成 NFO、海报或 STRM。视频不下载到本地，使用 115 接口重命名和移动。未选择文件、未匹配字幕、其他附件和原文件夹保留原位。

## 字幕、冲突与执行记录

- 字幕按同目录内的视频原名匹配，支持语言、forced 等点分隔后缀。多个视频同名而扩展名不同、无法唯一确定字幕所属视频时保留字幕原位。
- 自动提取常见分辨率、编码、来源标签作为版本标记，其他自定义版本可手动填写。多个文件整理后同名时需修改版本标记、季集或取消选择。
- 同名目标文件不会主动覆盖；来源目录重命名将产生同名文件时也会阻止。执行前会重新读取文件与目录。整理时请避免其他工具同时修改相同文件或目标目录，115 的独立接口不能提供跨工具的事务锁。
- 后台一次执行一个任务，关闭页面后继续。任务启动时固定账号凭据、目标和命名，配置变更不影响运行中的任务。
- 同一来源和目标目录的文件按每批最多 20 个处理；目录编号在任务内复用，文件列表在每批执行前重新读取。批量改名、移动后集中读取目录，逐个核对文件编号、名称和大小。同批未选中的文件不会被加入操作。
- 执行记录显示已完成批次和累计耗时。“查看耗时详情”可查看请求次数、接口响应、排队 / 限速等待、目录读取和本地记录保存耗时。目录和写操作的累计耗时已经包含请求等待，不能与请求等待再次相加；统计在阶段结束时刷新。重启后保存耗时不包含最后一次写入本身。
- 每批修改前保存阶段记录，批量接口即使返回成功也会逐项核实。部分成功、超时或结果无法确认时，保留各文件的已完成、已命名或待核实状态并停止后续批次，不自动重试写操作；记录中可查看原路径、目标路径和最后阶段。
- 同一预览重复提交会返回原任务。服务重启后进行中的任务标记为中断，不自动重放。文件可能已改名或已移动，请先检查当前网盘位置，再重新选择并预览。
- 配置和最近 30 个任务保存在数据目录的 `manual-organize.enc`，任务记录不包含 Cookie。扫描和未提交预览仅在内存保留 30 分钟；服务重启后需要重新扫描。

单次扫描最多 1000 个媒体文件、300 个目录、12 层深度。目录过大或包含多部作品时，请进入子目录分开整理。
