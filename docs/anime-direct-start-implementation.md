# 动漫配置页直接开始订阅

> Historical development record. Retired activation/history-selection flows and real test records were removed in v53. Current behavior: [configuration and RSS lifecycle](anime-subscription-dialog-plan.md).

2026-10-20。按用户最新要求，取消保存草稿、保存为暂停，以及详情页再次预览启用的流程。本记录优先于早期方案中的草稿与首次启用设计。

## 页面行为

- 配置来源、规格、补番起点、TMDB 命名与共用目录后，在当前页面开始订阅。
- 尚无有效预览时，唯一主操作为“预览并核对”。仅串行读取缺失或失效来源，已有有效预览复用；全部成功后恢复原来源标签。
- 核对当前选择后点击“开始订阅”，直接提交当前来源预览及完整已选资源 ID，不再跳详情重新读取 RSS。同集多个版本按资源保留，条数不称为集数。
- 合法的零发布或零匹配可开始等待更新。完全空白的备用不提交，已填写但未配置完整的备用必须完成或移除。
- 预览过期、规则变化、旧选择未核对时保留保护。明确失败保留未提交输入；未知回执锁定输入并以原请求键、正文核对。成功后显示“已开始订阅”。
- 列表、卡片状态和说明不再提供草稿；详情删除首次启用面板及未执行预选提示。运行后的暂停、恢复、归档、移除继续使用原有生命周期。

## 后端

- 新入口 `POST /api/admin/anime/subscriptions/start`。旧未开始配置可使用 `POST /api/admin/anime/subscriptions/:id/start`，已运行订阅不能通过该入口改写配置。
- 原 POST/PATCH 配置保存与 enable-preview/enable HTTP 入口关闭。生产服务不再导出保存未开始配置的方法；历史配置构造只供回归夹具使用。
- 拆出配置保存、启用的事务内操作。篇章、订阅、来源、历史基线、逐资源决定与幂等回执在同一 SQLite 事务提交；中途失败全部回滚，不留下可见的暂停半成品。
- 原预览按管理员、表单/篇章范围、配置版本、完整设置快照、来源规则指纹、来源预览及加载版本、有效期逐项核对。仅将已验证预览的临时来源标识转换为稳定标识，保留发布内容、观察、T0、选择和到期时间。不同来源可引用不同批次的有效预览。
- 仅明确选中的历史资源获得执行许可，未选择历史冻结为跳过；不合并同集不同版本、不自动补选。保留既有下载核验及去重链路。
- 开始只读取已保存预览和本地账号/目录快照，不重复读取 RSS，不新增 115 目录、SHA1 或文件核对请求。后续任务仍按固定主账号下载到目录 1，再标准命名移动到目录 2。
- 修正配置深拷贝复用调用者切片/指针的问题，避免并发原请求得到不同摘要。幂等回执优先于版本、元数据及有效期检查。
- 无数据库版本变更、清库、Emby 联动或真实云端文件操作。
