## 状态与请求

`useAnimeDiscovery.ts` 保存最多 32 项内存资料和 32 项滚动位置。资料新鲜度使用后端 `expiresAt`，不由前端自行续期；详情与关系分别缓存。过期内容可即时展示并刷新，失败保留旧内容与实际错误，首次无缓存失败显示独立错误空态。

`view/day/q/page` 在 URL 中恢复；日历与搜索切换时保留另一视图的上下文，`view` 明确决定当前视图。离开后从菜单返回恢复最后视图、星期、搜索页码和滚动。不同关键词/页码使用不同结果键，不能把旧查询结果放在新标题下面。整页刷新可通过 URL 恢复筛选，内存缓存和本工具记录的滚动位置不跨浏览器刷新或重启持久保存。

新查询、离页及篇章切换取消旧请求，另以请求身份/会话代次拒绝迟到结果。详情与关联使用独立控制器。令牌、用户 ID 或角色变化清理缓存；同一身份的定时登录校验不清缓存。空令牌、旧令牌或非管理员不发送请求。上游限流期间阻止重复读取，到期恢复重试。

显式刷新不恢复旧滚动，不重建同 ID 卡片或回到骨架；未命中缓存时，仅在有保存位置且用户尚未交互的条件下补做滚动恢复。动效只在支持悬浮的精细指针设备触发，共享光效只动画透明度/位移；触屏及减少动效偏好不运行持续光效，无轮询、Canvas 或逐卡 JavaScript 定时器。
