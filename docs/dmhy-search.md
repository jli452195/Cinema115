# 动漫花园搜索

影视详情页的“动漫花园搜索”直接读取 `share.dmhy.org` 的关键词搜索网页。入口对管理员开放，适用于电影和剧集；与 Mikan、Anime Garden 共用资源弹窗、批量选择、云下载及下载整理交互。

搜索默认使用当前作品中文标题，可切换原名或手动修改。仅默认标题首页确实没有条目时尝试原名；非影视结果、无磁力条目及当前范围无结果均不会触发自动改词。年份和季号不作为搜索结果的拦截条件。

## 分类与分页

后端保留原站各类条目，前端默认显示“影视”，提供“补充”“全部”范围：

| 范围 | 原站分类 |
| --- | --- |
| 影视 | 动画 2、季度全集 31、日剧 6、RAW 7、特摄 12 |
| 补充 | 其他 1、音乐 4、动漫音乐 43、同人音乐 44、流行音乐 15，以及未知分类 |
| 全部额外包含 | 漫画 3、港台原版 41、日文原版 42、游戏 9 及游戏细分类 17–21 |

范围和规格筛选只影响已加载结果，不丢弃其他分类，不按标题中的“漫画”“CD”等字样删除混合合集。计数表示已加载条目，不代表全站总量。当前页没有影视条目时仍可继续加载原站下一页；切换范围不会重新搜索，也不清除跨范围已选资源。追加分页遇到重复原帖时保留已加载的条目，避免覆盖用户刚补读的磁力；重新搜索或刷新首页才替换结果。原站动画大类包含季度全集，本接入使用全站关键词查询，不重复请求父子分类。

列表同时读取下载列的磁力 `href` 和迅雷按钮上的 `data-magnet`，不执行原站脚本、不访问迅雷或其他第三方下载链接。Base32 和十六进制身份统一后比较，同一条目的多个有效声明必须指向同一 hash。缺失、无效或冲突只影响该条目，其他结果仍正常展示。

列表未提供磁力或内容无效时，可点击“读取磁力”查询这一条原帖；搜索不批量请求详情，读取磁力也不获取 `.torrent` 或提交 115 下载。成功后恢复复制、云下载、整理和批量选择；磁力身份冲突时保留原帖入口，提示人工核对。不同原帖按帖编号保留，批量提交沿用现有 BTIH 去重和提交回执处理。做种数为原站当次查询信息，不代表 115 下载一定成功。

## 下载整理与访问

点击整理后读取原帖和 `.torrent`，以所选磁力、原帖磁力与真实种子 info-hash 三者核对身份，从种子中解析精确文件清单，再进入公共整理流程。网页展示的文件列表不用于生成整理清单；原帖只有磁力而没有可用种子地址时，仍可复制或普通云下载，整理会提示无法取得种子清单。普通云下载沿用主账号和已配置目录，整理任务沿用固定凭据、目录归属校验、恢复及分享 STRM 流程。

管理员搜索接口为 `POST /api/admin/dmhy/search`，输入包含 `query`、`fallback`、`group`、`page`、`refresh`。搜索只读取列表，响应提供分类、发布信息、磁力、分页及缓存时间。清单接口沿用 `POST /api/admin/p115/download-organize/files`，来源为 `source: "dmhy"`，携带数字 `providerId` 和 `magnet`，不接受任意网页或种子网址。

单条磁力接口为 `POST /api/admin/dmhy/magnet`，只接受数字原帖编号 `id`，返回核验过的原帖编号、磁力及缓存时间。它与整理共用详情缓存，整理仍单独核对调用方选择的磁力和实际种子身份。

搜索和详情使用本站独立的有界缓存、请求合并、访问间隔与冷却。出站域名固定，种子仅允许核验过的 `dl.dmhy.org` HTTPS 地址；网络代理设置中的“动漫花园”独立于 Anime Garden。页面结构异常或验证页面返回明确错误，失败刷新不覆盖已有成功结果。
