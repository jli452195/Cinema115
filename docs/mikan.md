# 蜜柑搜索

管理员在动画电影或动画剧集详情页点击「观影搜索」后的「蜜柑搜索」。入口按 TMDB 类型列表包含动画（ID 16）判断，不限制国家，支持日漫、国漫及其他地区动画；普通影视或尚未标注动画的作品暂不显示。默认搜索中文标题；正常零结果且原名不同时自动尝试原名。可以手动改词、切换原名，搜索失败或访问受限不会被当作零结果，也不会触发兜底。暂无登录设置，不使用 RSS 作为完整搜索来源。

后端只读蜜柑公开搜索网页，解析标题、大小、更新时间、磁力、种子及原帖地址，保留取得的全部结果并按磁力哈希去重。前端每次显示 50 条，可加载更多。字幕组使用原站提供的筛选编号重新查询；关键词和分辨率在本次结果内筛选。分辨率从标题推断，未识别的归入未知；不会把标题中的字幕组、季集号当作精确元数据或自动匹配 TMDB。

搜索接口为管理员鉴权下的 `POST /api/admin/mikan/search`，参数为 `query`、可选 `fallback`、`group` 和 `refresh`。上游固定为 `https://mikanani.me`，不接受自定义抓取地址，不执行原站脚本，不抓取广告、播放页或逐条详情。请求设置超时、响应体大小限制，同一时刻只访问一次蜜柑，相邻请求至少间隔一秒。同一关键词和字幕组请求合并，关闭页面取消等待。

有结果缓存十分钟，正常空结果缓存一分钟，缓存最多保留十六组；强制刷新跳过已有缓存，但复用相同的进行中请求。异常不会缓存为空结果。日志页面模块为「蜜柑」，显示搜索条件、结果数、缓存命中、兜底、耗时和错误，沿用所有模块共享的最近 2000 条内存日志。

资源的「115 转存」复用 `/api/admin/p115/cloud-download` 的配置和提交接口，使用该功能已明确绑定的账号与目录；未配置账号时提示配置，不选择其他账号。点击后显示已提交，不等同于下载完成。复制磁力失败时显示可手动复制的文本，适配局域网 HTTP 页面中剪贴板不可用的情况。

验证：`go test ./...` 与前端 `npm run build`。可选公开站点只读检查：设置 `MIKAN_LIVE=1` 后运行 `go test ./internal/client/mikan -run TestLiveSearch -v -count=1`，不会下载种子或提交云下载任务。

界面模拟检查：启动前端开发服务后执行 `node frontend/scripts/mikan-search-ui.cjs`。可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`CINEMA_URL` 指定本机测试依赖和地址，所有应用接口均拦截为模拟响应。
