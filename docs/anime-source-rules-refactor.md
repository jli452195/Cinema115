# 动漫来源正则规则重构

实现日期：2026-10-22。用户确认当前均为开发测试数据，不保留旧订阅兼容。

## 问题与参考

旧实现将解析器版本作为执行授权条件。解析器从 v4 升至 v5 后，旧来源会被标记为不可用并停止调度，而订阅仍显示启用；恢复 RSS 入口也不能解决认领、提交阶段的同类拦截。

参考 ANI-RSS 提交 `c5ca167f3c70b4bc6d83a15a20f2fde98d201cfc` 的 `Ani.java`、`ItemsUtil.java`、`RenameUtil.java` 与 `AniView.vue`：订阅持有匹配/排除表达式和集号提取规则，解析失败只影响单条发布。本项目保留默认解析、不洗版、字幕组独立版本和低请求下载整理流程。

## 当前规则

每条主 RSS 或备用 RSS 保存一份 `AnimeRules`：

| 字段 | 行为 |
| --- | --- |
| `match` | 全部正则均命中标题才匹配；空列表不限制 |
| `exclude` | 任一正则命中即排除 |
| `episodePattern` / `episodeGroup` | 可选的集号正则与捕获组；留空使用默认解析 |
| `minimumEpisode` | 字幕组标题编号的下载起点，包含本话 |
| `chapterFirstEpisode` | 现有篇章编号映射依据 |

使用 Go/RE2，默认区分大小写，可在表达式前添加 `(?i)`。每行一条，逗号保留用于量词；匹配/排除分别最多 20 条、每条 512 字，集号正则最多 2048 字。捕获组必须存在，提取结果须为 1～99999 的整数；集号表达式无匹配或匹配多次时不回退猜测。

来源选择中的规格单选模板生成可编辑的正则。切换模板保留排除与集号规则，可恢复打开时的匹配规则；不保存旧 `specMode`、`specProfiles`、`resolution` 或 `include` 规则。解析规格仍用于展示、模板建议及版本防重。

预览和保存均由后端验证正则，返回来源、字段和行号；前端定位至对应主/备用 RSS 输入，不用 JavaScript 正则替代 RE2 校验。

## 执行与缓存

删除持久解析基线及所有基于当前引擎版本的执行放行条件。解析器/规则/时间版本只用于解释缓存失效和诊断；未选中的旧结果重新计算，已选快照冻结，显式排除不自动恢复。

共享发布缓存仅保存资源身份与内容，各来源保存独立解析/决策快照。预览、发现、认领、下载提交和记录展示使用同一来源解释，避免一条 RSS 的自定义集号覆盖另一条。

下载账号、UID、凭据版本和实际目录校验继续生效。共享设置版本因单独修改整理配置递增时，不阻塞下载目标未变的任务；每个实际写入仍使用固定的任务快照。目录修正或完整配置保存可重新调度对应不可用来源。不增加 115 查询。
