# 公共可视化命名模板

电影、剧集各保存一份结构化模板，共用字段库、可视化编辑器和后端命名引擎。目录与文件名逐层编排；需要命名的业务提供已有事实，不在命名引擎中请求 TMDB、115 或解析视频流。

## 实施任务

- [x] N-01 公共命名内核：字段库、电影/剧集默认模板、分层相对路径、空字段省略、编号和扩展名保护、路径校验及测试。
- [x] N-02 设置与编辑器：服务端保存电影/剧集模板，公共预览接口，可视化层级与字段编辑，Gemini CLI 交互审查。
- [ ] N-03 手动及下载整理接入：共用命名与预览，任务固定模板快照，字幕跟随最终视频名，保留同名冲突检查，删除替代的固定拼接逻辑。
- [ ] N-04 动漫订阅接入：编号映射结果输入公共命名引擎，保存任务所用模板快照，删除替代的目录/名称拼接和前端重复预览。

## N-01 接口与边界

模块：`backend/internal/naming`，仅使用标准库。

- `Catalog(kind)`：编辑器可用字段及分组。可填入某字段不代表当前来源能识别该信息。
- `Default(kind)`：返回独立可编辑的电影或剧集配置。
- `Compile(template)`：验证结构并复制模板；每个任务或批次编译一次，可并发复用。
- `Renderer.Render(data)`：返回目录、文件主名、扩展名、完整文件名和相对路径，不执行云端写入。

模板含 `kind`、`directories`（最多 4 层）与 `filename`。每层是有序字段块；块的 `separator`、`prefix`、`suffix` 跟随字段，`pad` 仅用于季号、集号。没有脚本、表达式执行或模板字符串解析。每层最多 32 个字段，同一字段在同层不能重复。

数据通过 `values` 提供名称、年份、规格等文本；`season`、`episode`、`endEpisode` 是可空整数，`originalName` 与 `titleOnly` 单独传入，不能用文本字段覆盖计算编号或扩展名。

规则：

1. 未知字段值为空，连同前后缀和所属分隔符一起省略。首个实际输出的块不输出前置分隔符。整层目录都为空时省略该层；保留作品标题内部的原有标点。
2. 文件名须有作品名称、原语种名称、英文名称或原文件名之一；渲染时该身份字段必须有实际值，不用画质字段拼成无作品身份的名称。
3. 剧集文件名须有 `seasonEpisode`，按 `S01E01` 或 `S01E01-E02` 输出；零季、零集有效，超过两位的编号不截断，不使用 TMDB 总集数作上限。目标季集由调用方先完成映射。
4. 扩展名取自真实原文件，统一小写并固定追加在末尾，不是可移动模板字段。只有标题的预览使用 `titleOnly`，不从标题尾部猜扩展名。返回独立的 `stem`，方便字幕跟随时避免对含点的预览名称再次猜后缀。
5. 文件名字段中的非法路径字符替换为下划线；模板装饰中禁止路径分隔符、控制字符和非法文件名字符。处理 Windows 保留名称；输出仅能位于调用方指定目录下。原文件须传入文件名而非路径。
6. 每个目录与完整文件名最多 240 个 UTF-8 字节，扩展名计入预算。超限明确报错，不截掉季集、版本等字段；同名冲突仍由现有整理链路检查。
7. HDR、SDR、位深、音轨等只使用明确提供的值，不推测、不读取视频流。合集的每个文件由调用方提供各自规格。

N-01 提供纯命名内核，设置存储与编辑器由 N-02 完成。现有业务接入和旧拼接删除在 N-03、N-04 完成。

## N-02 独立设置与编辑器

入口为管理导航中的“命名模板”，地址 `/settings/naming`，剧集使用 `?kind=tv`。不属于 115 网盘；模板仅生成相对路径，不包含账号、CID、绝对根目录或存储类型。后续 115、CD2 等接入方各自负责根目录与实际文件操作。

- `GET /api/admin/naming`：一次返回电影/剧集已保存模板、默认模板及字段库。
- `PUT /api/admin/naming/:kind`：提交 `revision` 和 `template`，两类模板独立保存。旧版本冲突返回 409，不静默覆盖；最后一次相同请求可重放，确认丢失的回执而不重复写入。
- `POST /api/admin/naming/preview`：接收模板与最多 50 条调用方数据，编译一次后生成预览，不保存配置、不查询资源。模板结构错误返回 400，单条素材信息不足返回该条错误，不能将素材不足等同于模板结构非法。
- 接口均要求管理员身份，正文最多 256 KiB，拒绝未知 JSON 字段。SQLite `naming_templates` 按作品类型保存模板与版本，未保存时返回版本 0 的默认模板。

`NamingTemplateEditor.vue` 只接收结构化模板和字段库，可独立复用。支持目录层、字段添加、同层拖动排序、键盘与按钮排序、前后缀/分隔符和数字补零；扩展名固定跟随原文件。电影和剧集切换保留各自编辑，重读或恢复默认只替换当前类型。预览采用 300ms 防抖与取消/序号校验，中文合成输入结束后才提交，更新期间保留上次路径并显示加载状态。预览不请求 115、TMDB 或 RSS。

保存中禁止重复操作；网络异常导致结果未知时保留原正文，使用“确认保存结果”重放。冲突保留编辑内容，重读前确认放弃。离开页面保护未保存修改。窄屏格式输入使用两列，分隔符独占一行；预览在文档流中显示，完整路径可在内部横向滚动。
