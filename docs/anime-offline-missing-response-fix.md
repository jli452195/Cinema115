# 动漫离线任务查询误报修复

## 原因与修复

115 精确 Hash 查询返回 HTTP 200、`state:false`、`errcode:10021`（用户任务不存在），同时返回空 `info_hash`、空 `file_id`、零状态/进度等默认任务字段。旧解析器要求这些字段完全不存在，将正常的未命中误报为 `TASK_READ_FAILED`，提交前检查无法继续。

精确未命中现在允许已知的空字符串和零值默认字段；非空身份、非零状态/进度、嵌套任务或列表分页仍拒绝，不能据此提交。状态追踪复用同一判断。未知或已派发的提交依然只核对，不重发；既有离线任务不被接管。

页面按阶段说明错误：待提交任务明确提示尚未提交、后台稍后重试；已提交任务继续保留最后成功记录。已有任务/目录冲突提示不能直接用于本次下载整理。

115 的“已完成”仅代表远端任务状态；任务目录内没有有效文件时仍需处理，不能标记为整理成功。不清理旧种子记录，不增加正常流程的请求次数，不引入数据库迁移。
