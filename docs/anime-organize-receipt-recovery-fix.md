## 已修正的代码缺陷

1. 原批量回执解析器只允许空 `data`。新增改名报告兼容：当 `data` 是文件 ID 到新名称的对象时，必须恰好包含请求中的所有 ID，且名称逐一精确相等，才确认成功。部分、错误、重复 ID、额外项、异步回执和未知结构仍进入核对；移动不能借用改名报告证明成功。正常成功回执不新增 GET。
2. `CompleteAnimeDownloadWork` 原来给核对成功的整理步骤也追加五分钟异常退避。现在核对这一轮保持只读，成功后下一步保留同 UID 至少五秒间隔即可继续，异常、限流和已保存的更晚时间仍退避。
3. 原来回执不兼容的具体原因被丢弃。新增固定枚举 `receiptIssue`，只在未确认步骤保留 `invalid_envelope`、`error_field`、`unexpected_field` 或 `data_*` 类型分类，不保存上游响应正文、字段值、Cookie 或签名。确认成功后清空。该字段仅用于内部操作记录，不新增前端选项或数据库迁移。
