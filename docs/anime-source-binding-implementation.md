# 动漫来源与编号范围确认（P1-05）

日期：2026-10-18。

依据：[首版规则](anime-first-release-rules.md)、[数据与接口契约](anime-subscription-contract.md)、[来源读取](anime-mikan-implementation.md)和[发布解析](anime-release-parser-implementation.md)。

## 实现与边界

新增 `internal/service/anime_binding.go`，提供候选、来源确认及编号预览的只读服务。依赖仅为 Bangumi 详情读取、共享 MikanService 和本地篇章查询，不含存储写接口、115、TMDB 或媒体服务器业务。

- `SearchMikanCandidates`：按明确关键词，或选定篇章的中文名/原名调用已有蜜柑搜索。返回最多100个按条目ID去重的候选卡片、截断标记和真实搜索记录，不向调用方返回混合组资源全集。普通零候选与读取失败分别返回；同名候选不自动绑定或保存篇章。仍复用已有搜索缓存、请求合并及全站间隔，不逐候选补详情或下载图片。
- `MikanService.ReadAnimeMikanEntry`：在 P1-03 的预算、缓存和访问 gate 下获取实际条目与字幕组列表，不抓各组历史。新增条目ID、组ID/名称、重复组、长度/文本及实际读取时刻校验，失败在写缓存前返回，旧成功缓存保留。返回副本与缓存隔离。
- `CheckBinding`：解析本地篇章引用或从 Bangumi 获取可信详情，核验蜜柑条目与实际组关系，返回真实组名、固定站点URL、规范化单组RSS、显式输入的 binding、范围端点回显及缺项。它只确认来源与编号配置，不判断整个订阅、账号目录或下载是否就绪。无 RSS 成功记录也能完成元数据核验，后续可保存完整暂停配置。
- `PreviewBinding`：在上述核验之后读取一次单组 RSS，以 P1-04 解析器逐条解释编号并投影篇章范围。不选择、提交或保存发布；原始行数仍先于去重，RSS 范围保持 partial。失败没有正常的 `rawCount=0` 回执，成功空源明确返回0及空数组。

已有篇章只读本地固定身份，外部条目删除不妨碍保留身份和继续核对来源；不按标题认领或重绑。新 Bangumi 篇章只从可信详情建立待保存模型，所返回ID必须与所选ID一致。蜜柑快捷入口允许暂不关联 Bangumi，篇章标题取实际源站条目，不能提交任意标题代替。

这些服务尚未装配 HTTP 路由，不接受浏览器传回的预览结果作为授权。P1-07 在管理员边界重新调用核验，以返回的可信标题/组名组装配置，再使用现有 CAS/事务保存；本步的确认/预览调用本身不写数据库。P1-06 接入筛选、历史清单、预览版本及发布时间边界。

## 外链与人工确认

蜜柑条目读取额外保留最多32个去重的 Bangumi subject ID，只接受 bgm.tv、bangumi.tv、chii.in 的明确 HTTP/HTTPS `/subject/数字ID` 地址；不接受凭据、端口、查询、片段、编码路径和伪装域名，不访问这些链接。

外链一致只产生 `BANGUMI_LINK_IS_HINT` 注记，不修改 `binding.confirmed`。与所选篇章不一致时附加 `BANGUMI_HINT_DIFFERS`，不悄悄切换篇章，也不把某个外链当作不可推翻的归属证明。相同名称与单个外链均不能替代人工核对发行版本。

来源须显式确认并指定 `scope`：

- `range`：有限且包含端点的来源集号范围，混合篇章来源应选择本篇章的明确范围；仅填补番下限不能代替范围。
- `confirmed_chapter`：管理员明确声明来源仅属于当前篇章，必须填写人工核对依据。程序不从名称、外链、最大/最小已见集号或 Bangumi 总集数自动作出该声明；已知混合篇章来源不能用它替代有限范围。

此人工依据不是自动证明源站未来不会混入其他篇章。不能可靠确认范围的来源保持草稿；未完成的备用源不向其他来源继承确认结果。主/备用及配额总数仍由现有订阅配置存储校验。

## 编号投影与持久化边界

新增独立纯计算包 `internal/anime/binding`。`Project(binding, parse)` 输出 `in_scope/out_of_scope/needs_confirmation`、原始来源整数及可选篇章序号，保留原始标题和解析结果供解释。计算只使用该来源明确保存的基准：

```text
篇章序号 = 来源集号 - 对应基准的来源集号 + 对应基准的篇章序号
```

例如甲组基准26→1，来源30显示篇章5；乙组独立基准1→1，来源5也显示篇章5。同集不同版本分别投影，不共享编号空间或占位，不按集号互斥。

补番下限不参与换算，也不由基准反向改写。范围已确认但对应基准未填写时，可确认来源归属，篇章序号保持未知，不推断偏移。未知解析、SP、A/B、合集及复合编号保留待确认，不投影成普通集。来源超出人工范围时返回 `OUTSIDE_CHAPTER_SCOPE`。

模型额外校验有限范围两端的换算必须落在1～99999内，防止基准与范围矛盾被持久化。基准可以位于本次有限范围之外，只要范围内换算有效；例如基准26→1、范围30～38仍合法。独属篇章来源无有限端点可预检，单条换算越界时返回 `CHAPTER_NUMBER_UNRESOLVED`，不会伪造第0集或负集。

沿用现有 binding JSON/schema、来源 revision/namespace 和 SQLite 表，没有新增迁移。现有来源不能原地更换条目或组；替换仍通过软移除旧源并新增来源完成，旧发布决定和历史保留。新服务不创建订阅、基线、初批清单、调度时间、任务或文件。
