# 我的播放 UI 与交互方案

2026-10-14。基于 `/account/playback` 实际页面、现有 Vue 组件和后端状态，与 Gemini 两轮讨论后收敛。附 [可点击原型](./personal-playback-ui-prototype.html)。正式页面已按本方案实现，验证与审查记录见文末。

## 页面结构

把常驻配置表单改成“播放概览、个人网盘、播放子账号”。沿用站点浅灰背景、白色卡片、蓝色操作按钮和 SVG 图标，兼容深色模式。

标题、面包屑和卡片统一约 1040px 内容宽度。当前页面标题与内部 `max-w-3xl` 正文错位；改版时需让 `ManagementLayout` 的标题容器也服从相同宽度，而非只改内部卡片。

1. **播放概览**满宽：突出当前来源与检查结果。“打开 Emby”为主操作，“检查状态”为次操作。底部紧凑显示 Emby 用户名、原文件直链说明；地址、复制地址与下载说明按需查看。来源直接叫“管理员主网盘 / 管理员动态池 / 我的 115 网盘”。
2. **个人网盘**：显示绑定 UID、已保存凭据、目录编号、是否用于本人当前播放。更换目录、重新扫码或换号按需打开面板；解绑放在管理面板内。健康用户不再看到“开通播放”的标题、常驻同意框和目录编辑表单。
3. **播放子账号**：显示配额、紧凑账号行和“新增子账号”。创建、继续原任务、改密和永久撤销按需打开。卡片内直接说明共享的是本人已绑定的个人网盘。

桌面下方两列，网盘列略宽；800px 以下单列，顺序为概览、个人网盘、子账号。桌面任务面板宽约 530px，手机全屏，内容独立滚动，底部动作和安全区始终可达。正式实现需检查软键盘下可视高度，不仅依赖 `position: fixed`。

采用同页卡片而非顶层页签：当前来源、个人网盘和子账号的关系同时可见，绑定异常及待完成任务不易被切页遗忘。帮助与隐私入口放在页面底部，扫码时仍完整展示必要告知。

## 状态与字段

| 条件 | 展示与下一步 |
| --- | --- |
| `enabled=false` | “直链服务暂未运行，仍可打开 Emby 浏览和管理个人网盘”。保留有效 Emby 浏览链接；不将网盘标记为失效。 |
| `source=assigned` | “共享池自动调度，播放时检查”。不让用户选择池账号，不声称池空闲或保证能分配。异常时保留后端说明。 |
| `stage=ready` | 个人或主网盘来源显示“网盘最近检查通过”。这是检查快照，不是实时播放授权。 |
| `stage=pending` 或请求异常 | 保留服务器 `message`；无法区分登录、目录和临时网络问题时用“需要检查”，不统一标为凭据失效。 |
| `connected=true` | 仅显示“已保存登录凭据”。后端只检查 Cookie 非空，不能因此显示“健康”“在线”或“可播放”。 |
| 无个人绑定，允许准备 | 显示简短绑定引导。当前是管理员来源时明确“准备个人网盘不会改变当前播放来源”。 |
| `source!=personal && !canPreparePersonal` | 只读说明当前管理员来源。已绑定个人网盘仍展示归属与目录，不提供扫码、改目录或切来源；现有解绑能力保留在本人管理入口。 |
| `pendingDrive=true` | 主卡显示可恢复任务，区分当前绑定 UID 与 `directoryAccount.uid` 的待绑定 UID。提供“继续选择目录 / 取消本次绑定”；不能再次发起扫码。首次绑定没有旧账号时直说“尚无已生效的个人绑定”。 |
| `directoryAccount.creationUncertain=true` | 明确创建结果未确认，禁止再次创建，保留浏览和选择已有目录。 |
| `source!=personal` 且个人网盘已准备 | 标注“未用于本人当前播放”；允许时提供显式“切到我的网盘”。此状态不代表个人网盘已通过实时健康检查。 |
| 无有效 `embyUrl` | 不生成不可用链接，显示“Emby 入口尚未配置，请联系管理员”。只接受 HTTP / HTTPS。 |

不显示 API 未提供的最近检查时间、存储余量、网速、观看设备或播放会话统计。`MemberPlaybackView` 目前未返回 `checkedAt`；浏览器的获取时间不能冒充网盘检查时间。`allowDownload` 仅说明服务总开关，不能替代 Emby 用户的下载授权。

普通用户仍以 Emby 登录。`unbound`、`bound`、`creating`、`provisioning` 等残余/处理中状态不通过文案引导重新注册已有 Emby 身份；显示后端说明并提供刷新或联系管理员。

## 个人网盘流程

### 首次绑定、重新登录和换号

1. 打开任务面板，展示凭据保存、秒传占用空间、已记录文件副本参与只读校验、不扫描其他文件、不进入公共池、管理员不可读取或修改个人 Cookie 的说明。勾选同意并选择登录客户端，再获取二维码。
2. 展示真实扫码状态与过期提示。更换客户端令旧码失效，关闭面板停止轮询；只创建二维码不等于已创建持久绑定。遵守后端二维码刷新限制，不加自动连续刷新。
3. 扫码完成后采用返回的完整状态分流。同 UID 续登且目录仍有效可直接完成；`pendingDrive=true` 或目录未就绪才进入目录步骤。不能仅凭 UID 相同跳过后端要求。
4. 目录步骤明显标出本次目标 UID，使用捕获的 `directoryAccount.accountId/revision`。禁止根目录直接成为保存目录；允许在根目录下新建 Cinema115。手工目录编号收在次要入口。保存失败保留输入、原绑定和当前来源。
5. `/directory` 确认成功后，才更新已绑定身份。本人当前使用管理员来源时，单独显示“个人网盘绑定完成，当前来源仍为管理员来源”，提供“保持当前来源 / 切到我的网盘”。切换另行调用 `/use-personal`，不能合并成乐观成功。

扫码后的待绑定是服务器持久任务。关闭面板、Esc、刷新页面均不自动取消；主卡提供继续入口。显式取消通过 `/drive-change {cancel:true}`，保留原绑定。后台返回账号或版本变化时，停止旧二维码与目录提交，重新读取状态并要求重新选择。

切换确认提示：“后续播放使用你的个人网盘，文件占用个人空间。此页不提供切回管理员来源；凭据失效后不会自动回退。”不称“不可逆”，管理员仍可调整来源。前端不新增管理员来源选择器。

### 目录变更与解绑

目录变更只作用于新任务，已启动任务固定原凭据与目录，旧文件保留。仅浏览不提交；新建目录本身是写入动作，按钮明确为“新建并使用”。目录创建结果未确认时禁止重复创建，不能把网络错误当成不存在。

解绑使用明确确认面板及一个勾选框，无需输入确认词或倒计时。按来源说明：个人来源拒绝本人新的播放取链；管理员来源不受个人解绑影响。共同提示：共享此网盘的子账号新播放请求受影响；清除本人个人配置、凭据和关联；网盘已有文件保留；已签发直链不保证立即失效。没有权威数量时不显示受影响的子账号人数，`used` 包含创建中账号。

## 播放子账号

- 配额沿用后端 `used/limit`，本人不计入。配额满用中性提示，不当故障标红；创建中、暂停共享和停用登录均占名额，永久撤销才释放。配额为零且无历史任务时隐藏模块；请求失败仍展示重试入口。
- 未绑定个人网盘或无目录时解释前置条件，阻止新增，但已有子账号仍可查看和进行后端允许的停用、改密、撤销等管理，不因网盘缺失把整个模块锁死。`connected` 只能用于排除明确缺凭据，最终创建资格由后端核验。
- 未完成创建任务置前，显示“继续原任务”。固定 `requestId` 与用户名，要求重新输入首次提交的密码。网络结果不明先读取服务器任务，不自动重新创建外部用户；仍无法确认时保留任务标识。每次提交后清空密码，关闭面板也清空密码。
- `paused` 与 `disabled` 独立展示，可同时出现。动作叫“暂停共享 / 恢复共享”“停用 Emby 登录 / 启用 Emby 登录”，旁边解释区别，不压成单个启用开关。
- `blocked=true` 说明“已停止托管：账号已被设为 Emby 管理员”，锁定托管操作；不误称网盘故障或账号封禁。
- 重置密码提示不保证已登录设备立即退出。永久撤销强调不能恢复共享、保留禁用身份与观看记录、释放配额、后续请求被拒绝及已签发地址可能有效。
- 子账号固定属于本人，只能登录 Emby，不可登录网站或个人中心。共享本人已完成绑定的个人网盘，即使本人正在使用管理员来源；不提供主网盘或池账号选择。

## 实现与验收建议

第一版沿用已有 API，不新增后端业务能力。`PersonalPlaybackView.vue` 保留唯一权威播放状态，拆出概览、网盘摘要与任务面板；`PlaybackChildren.vue` 保留任务幂等与版本控制，替换常驻创建表单和大操作区。可复用 `P115SidePanel`、`P115ActionDialog`、`P115DirectoryDialog` 与 `P115Icon`；目录选择避免双重模态抢焦点，优先在同一任务面板内换步骤或明确关闭上一层。

请求期间展示对应操作进度并防重复提交，服务器确认后更新摘要；失败保留可恢复输入并就近显示错误，重读当前状态。两个模块独立显示失败，不因子账号列表失败清空播放概览。焦点限制在模态内，Esc 可关闭，关闭后返回触发按钮；触发按钮因状态更新被移除时返回对应卡片的稳定标题。状态播报与文字标签不只依赖颜色。

正式开发验收覆盖：

1. 已绑定健康用户首屏无常驻同意/扫码/目录/创建表单，“打开 Emby”突出；标题和卡片左边界一致。
2. 管理员来源准备个人网盘不自动切来源，管理员来源和个人归属始终可区分。
3. 首次绑定与换号中途关闭、页面刷新可继续；旧绑定仅在新凭据和目录成功提交后切换。
4. 同 UID 续登按权威状态恢复目录；二维码过期、切客户端和离页停止旧轮询，旧结果不得覆盖新状态。
5. 目录账号/版本冲突、保存失败和创建结果不明保留原绑定，不重复创建、不改错账号。
6. 解绑区分本人当前来源影响，明确子账号影响，不承诺立即撤回 CDN 链接。
7. 子账号任务继续、双状态、已停止托管、配额耗尽、永久撤销与已撤销历史均准确。
8. 320/390/1440px、浅深色、键盘和实际手机软键盘：无横向溢出、焦点可见、内容可滚动、底部动作可达。

## 正式实现与审查

`PersonalPlaybackView.vue` 已接入播放概览、个人网盘摘要与任务面板；`PlaybackChildren.vue` 已改为紧凑列表及按需创建、管理面板。标题与内容统一宽度，桌面双列、手机单列，支持浅深色。未新增业务 API 或修改 Emby 授权逻辑。
