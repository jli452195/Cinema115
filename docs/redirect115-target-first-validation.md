# redirect115 目标优先查询验证

2026-10-06：带 SHA1 的 redirect115 无本地资料、来源关联和目标副本记录时，先按 SHA1 查询本次固定的目标账号。正式播放用目标取链响应核验文件 ID、SHA1、大小；提前文件准备使用目标元数据核验，不获取 CDN 直链。成功后保存目标返回的资料及 UID 副本，不添加外部 PickCode 的可信来源关联。

明确未命中才查询主账号补齐大小等资料，相同 SHA1 的查询结果在本次请求复用；若主账号返回不同 SHA1，丢弃原结果并按实际 SHA1 查询。错误、取消、限流或超时不允许上传。已有资料、来源冲突、多大小歧义、未确认上传及旧副本恢复保留原路径。无 SHA1 和分享来源不启用此优先查询。play115 另按完整声明直接准备资料，详见 [play115 验证记录](play115-declared-validation.md)。

查询预算为 5 秒。目标命中时正式播放不提前检查保存目录，正常路径为 SHA1 查询加取链两次请求；保存目录只在明确未命中、准备秒传时检查，并由上传预检复用这次成功结果，避免重复请求。相对原来并行查询主账号和目标的路径，目标命中省掉主账号查询；未命中时会增加等待目标查询的串行时间，不承诺所有首播都更快。115 二次校验规则保持不变。

## 验证命令

在 backend 目录运行：

```powershell
go test ./... -count=1 -timeout=180s
go test ./internal/service ./internal/httpapi -run 'TestRedirect115|TestFileReuseDeferredAuthorization|TestPickCodeReuseCanaryPoolHTTP' -count=20 -timeout=180s
go vet ./...
go build ./...
```

完整后端回归、20 轮隔离灰度及故障回归、`go vet ./...` 和 `go build ./...` 均通过。服务测试覆盖冷命中、无主账号凭据、文件准备、未命中去重、主账号不可用、查询异常、身份错误、UID 错误、来源冲突、大小歧义、未确认上传和取消；补充验证了主账号 SHA1 不同不能复用原未命中结果，以及 SQLite 持久化后重启仍可复用。HTTP 隔离灰度经过真实 loopback 入口及完整 Emby/动态池授权流程，验证冷命中主账号请求和上传均为 0、再次播放不重复查询、缓存命中仍检查凭据、过期凭据不能返回直链。

本轮 race 检查未完成：Windows 没有可用 C 编译器；Linux 测试镜像也缺 gcc，临时容器安装编译器持续下载缓慢，已停止。不得将上述自动回归记作 race 通过。

目录延迟检查补充覆盖：冷命中不探测目录、文件可读但保存目录失效仍可复用、未命中写入前只检查一次、失效目录阻止上传、查询失败及身份冲突不能提交、取链期间停用阻止提交，下载与文件准备保持原检查。客户端协议测试实际执行模拟秒传提交，确认上传预检复用目录检查，不再请求一次目录接口；根目录回退被拒绝。文件取链成功不标记保存目录健康。
