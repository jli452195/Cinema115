# 搜索日志

实时日志页面的「搜索」模块统一收录详情页 RE0、Bot、观影、蜜柑、Garden、蜗牛的资源搜索日志。每条记录通过来源字段区分站点，通过操作编号关联开始与结果；现有关键词搜索同时匹配来源和编号，不增加来源选择器。

搜索弹窗的「查看日志」统一进入 `/logs?module=搜索&level=ALL`。普通结果记 INFO，缓存及详细过程可见 DEBUG；请求异常和取消分别保留错误或警告，不将正常零结果当作失败。RE0 提交转存或 STRM 时隐藏跳转入口，等待写入结果后恢复。

Telegram 登录、配置和机器人运行仍属于 Telegram，RSS 轮询属于订阅，115 下载与整理沿用自己的任务记录。观影、蜗牛已有的站点配置诊断随站点搜索日志归入「搜索」，避免另留站点模块；不重复记录相同操作。

继续使用已有管理员日志接口和共享的 2000 条最近记录；INFO、WARNING、ERROR 另存 JSONL 轮转文件，重启恢复已保存的最近记录。DEBUG 仅在最近记录中排障，不增加站点请求。新增摘要仅记录预定义操作、结果数量、页码、缓存和 HTTP 状态，不读取请求体、原始响应、凭据或带签名的资源链接。文件保留与下载方式见 [日志持久化](logging.md)。
