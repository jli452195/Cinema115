# 用户播放会话管理

同一 Emby 用户允许多个播放会话，不再按用户返回 USER_PLAYBACK_CONFLICT。各来源仍遵守实时 Emby 权限、网盘绑定与禁用规则；小号池独立执行实际 UID 的容量与限速。

## 生命周期

1. 播放记录按 Emby 服务 ID、真实用户 ID、经过认证的客户端会话及条目区分。同一会话的媒体源变体共享生命周期，池目标分别记录容量。同会话并发请求用引用计数，失败请求不会释放其他请求的准备记录。
2. SQLite 提交成功后才发布内存状态；正式取链才创建记录，准备阶段最多 95 秒。下载不创建用户播放记录，动态池下载仍占 UID 容量。
3. 用户播放记录签发后保留 5 分钟，可信播放事件或 Emby Sessions 精确且新鲜的 LastPlaybackCheckIn 可续期，浏览活动不续期。池租期默认 5 分钟，已有池设置保持原值。[同设备连续播放接替](device-playback-handoff.md)须同时满足旧会话静默与新会话播放证据确认；仅取到下一片直链不结束旧会话。缺少可信设备信息、存在多个正式候选或尚未确认播放时仍独立计数，池占用可能达到容量上限。
4. 正常停止只释放匹配会话，允许原地址原地重播。请求代次阻止旧请求继续签发；停止响应不得释放新的重播代次。
5. 缺少 PlaySessionId 的事件按已认证客户端与条目唯一匹配；同时存在多个候选时不猜测，不误释放其他播放。
6. 管理员释放须提交对应代次，并拦截该旧会话的新取链；用户的其他会话不受影响。池已签发记录最多保留两分钟残余占用。

## 管理与边界

管理页面按会话展示播放记录；预计到期和已签发状态不代表真实 CDN 连接。服务重启保留记录，正常停止和管理员释放均不能立即撤销已签发直链。

浏览协商不准备网盘文件或获取直链；本次取消单路限制不改变云端文件准备时机。正式取链仍复核 Emby 权限、来源、网盘及租约代次，动态池故障切换不回退主网盘。

## 验证

覆盖同用户并行会话、同会话请求复用、来源变体、重启后新会话、停止隔离、无会话 ID 的歧义、重播代次和管理员释放；池容量与限速沿用独立测试。
