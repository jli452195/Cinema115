# 115 助手 UI 与交互方案

2026-10-14。基于当前 `/helper115` 页面、现有前后端字段，与 Gemini 三轮讨论后收敛。附 [可点击原型](./helper115-ui-prototype.html)，使用示例数据，不调用业务接口。

## 推荐结构

将“动态池容量与调度设置”大折叠块拆成常驻概览、卡片操作、设置面板和运行详情。继续采用现有浅灰背景、白色卡片、蓝色主按钮和 SVG 图标，支持深色模式。

1. **主账号**：满宽紧凑横向卡片。显示资源管理与默认播放职责、UID、会员/剩余空间、登录客户端、检测与扫码。配置 ID、凭据信息更新时间及更多操作进入详情，减少首屏高度和右侧留白。手机改纵向。
2. **共享池区头**：标题旁显示“配置数 / UID 数”。“添加小号”为主操作；“调度设置”“运行详情”为次级操作；“分配说明”“管理 Emby 用户”收进更多菜单。
3. **运行概览**：四项常驻指标：最近检查通过的参与 UID、本次运行取链成功率、最近取链耗时 p95、当前 API 等待。桌面四列，手机两列。
4. **情境提示**：单 UID 无备用、未完成配置、明确故障贴近概览；提示原因及下一步操作。未知或待复查不直接判定故障。无配置则展示添加引导。
5. **小号卡片**：账号名称、健康状态、UID、会员/空间、该 UID 名额占用、秒传目录、调度模式、检查时间、重新检查与扫码。桌面两至三列，手机单列。
6. **调度设置**：桌面右侧 540px 抽屉，手机全屏面板。分“容量与保留”“重试与冷却”“API 频率与通知”三组；底部固定保存、取消。
7. **运行详情**：容纳请求结果、耗时、业务准入拒绝、解析及副本复用、API 阶段/来源、最近十条健康事件及统计口径，不绘制没有历史数据支持的趋势图。

不采用“账号 / 运行 / 设置”三个顶层页签：账号状态、占用和异常处置需要同时可见；设置低频，通过面板访问即可。账号很多时再考虑搜索和筛选，当前优先减少冗余层级。

## 状态与指标口径

| 展示 | 现有字段与处理 |
| --- | --- |
| 配置数 / UID 数 | 配置数量与非空实际 UID 去重数量分别显示。二维码临时会话不算持久配置。 |
| 检查通过的参与 UID | 配置已登录、有有效目录、`mode=enabled`、`state=ready`，按 UID 去重。明确表示最近检查结果，不能称“实时在线”或保证下一次请求成功。 |
| 本次运行成功率 | `metrics.succeeded / metrics.requests`；无请求显示“暂无请求”。失败含业务准入拒绝，详情说明其不等同于上游故障。 |
| 最近 p95 | `metrics.p95Ms`；`samples=0` 显示“暂无样本”。最近最多 256 个完成请求，包含失败与重试，不是播放器起播耗时。 |
| 当前 API 等待 | `api.waiting`，表示等待 115 API 预算放行的请求，不称播放人数。 |
| 卡片 UID 占用 | `account.pool.sessions / settings.maxSessions`。同 UID 配置返回相同占用，注明共享、不累加。准备、活跃、残余使用后端返回值。 |
| 超上限 | 如 `4 / 2`，原数字保留，进度条视觉限制至 100%，显示“超过当前上限”。不声称降低上限会立即踢掉已有播放。 |
| 健康状态 | 使用服务端 `pool.state` 和 `checkedAt`；模式与健康分开呈现。配置已保存不等于健康，不再同时出现不加解释的“待验证”和“最近检查通过”。 |
| 检查时间 | 优先使用对应检查的时间；无时间显示“尚未检查”。会员空间的 `summary.checkedAt` 单独标注，不能冒充池健康检测时间。 |

目前 `/pool` 通过当前账号配置展示 UID 状态。换号或删除后的旧 UID 残余可能不在当前配置列表中，因此**不根据可见卡片推导全池总容量或完整占用**。若未来需要该大盘，需后端提供覆盖所有仍占用 UID 的权威聚合。`peakUidSessions` 是本次运行峰值，只进入详情，不能填当前占用。

## 交互规则

- **编辑设置**：打开时建立服务端快照和独立草稿。无修改时保存禁用；字段内显示单位、范围及必要帮助。每 10 秒继续更新运行信息，不覆盖草稿。取消、关闭、Esc 或遮罩退出有修改时确认放弃；没有修改直接关闭。
- **保存**：校验整数及后端现有范围；全局间隔必须不大于每 UID 间隔。提交期间禁止重复保存，失败保留输入并就近显示错误；成功更新已保存快照，关闭面板并反馈。“重置”若增加，只恢复上次保存值，不擅自覆盖为默认值。
- **参与调度**：服务端确认后显示新模式；仍受健康、目录与容量条件约束，不能承诺立即可播放。
- **停止新分配**：直接提交，成功反馈“已停止为此配置分配新播放，已有会话保留。”不误写为拒绝已有会话后续取链。
- **禁用**：确认正文为“禁用后拒绝使用此配置的后续取链。已签发的直链无法立即撤回。网盘文件不会删除。”失败保留原模式；不使用普通开关混淆停止分配与禁用。
- **刷新状态**：只获取服务端现有状态，按钮与说明明确区分主动网盘检查。失败保留旧数据，标记刷新失败及上次成功更新时间；下一次成功清除警告。
- **重新检查**：使用已有池检查接口，检查当前凭据和目录。显示对应小号忙状态，避免重复请求；遵守后端同 UID 去重、15 秒防抖、全局冷却和预算。请求结束后读取服务端健康状态，不能仅凭 HTTP 成功显示“检查通过”。同 UID 配置检查可避免同时触发。
- **添加与换号**：复用已有创建、扫码及目录流程；配置未完成卡片显示明确下一步。换号成功前保留原关联，不能在界面上先显示已切换。
- **可访问性**：SVG 配有可访问名称；状态有文字，不仅靠颜色。抽屉锁定背景滚动和焦点，支持 Esc，关闭后焦点回触发按钮。错误就近显示；保存反馈使用状态播报。

字段范围与当前后端一致：名额 1–20；尝试账号 1–3；总预算 5–90 秒；保留 5–1440 分钟；冷却 5–3600 秒；UID 间隔 100–10000 毫秒；全局间隔 10–1000 毫秒且不大于 UID 间隔。

## 情境文案

- 单 UID：“仅一个 UID 参与调度，暂无其他 UID 备用。发生限流或故障时需等待恢复，不会使用主账号替代。添加不同 UID 的健康小号可提供备用。”
- 所有配置明确处于故障/冷却：“参与调度的小号目前均处于故障或冷却状态。请检查登录、目录和恢复时间；系统不会使用主账号替代。”不因 `ready=0` 单独触发。
- 没有配置：“添加小号，完成登录并设置秒传目录后，即可参与调度。”
- 同 UID 多配置：“多份配置共用此 UID 名额，容量不累加。”凭据仍独立保存。
- 刷新失败：“状态刷新失败，显示上次成功更新的数据。”同时显示上次成功更新时间。

## 落地范围与验收

第一版可沿用现有接口，无需新增后端业务能力。`P115View.vue` 负责页面；将 `DynamicPoolSettings.vue` 拆成概览容器、设置面板和详情面板，统一池数据来源；扩展 `P115ManagedAccountCard.vue` 接收名额上限与调度操作，移除原折叠块中重复的账号操作。主账号与小号仍复用现有登录、目录、清除和删除对话框。Emby 用户设备策略留在用户管理。

验收重点：

1. 单 UID、同 UID 多配置、三个 UID、无配置和限流场景展示准确，不将配置数当容量倍数。
2. 零样本无 `0ms`、`100%` 伪数据；检查结果与调度模式独立，未知不等于故障。
3. 编辑超过一次刷新周期仍保留输入；失败保留草稿；有修改退出才确认。
4. 下调上限保留真实占用数字；禁用、停止分配、恢复参与的文案与行为分别准确。
5. 手机 390px 无横向滚动，设置面板可滚动，保存按钮可达；深色模式及键盘焦点可用。
