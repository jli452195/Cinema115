# 动漫整理快照、命名与路径预览

2026-10-20，P3-04～06。依据用户最新要求，默认按标准命名整理，删除整组“下载后的处理方式”及其保存接口，不增加整理开关。云端改名、移动执行由 P3-07～08 接续，本轮 `capabilities.organize` 仍为 false。

## 任务与目录

- 下载目录1保持每条资源独立子目录；整理目录2保存标准作品目录，两者必须属于同一固定主账号且 CID 不同。
- 选择目录2复用现有目录选择器。保存接口只核实选定目录一次，不重复读取目录1，不读取文件或 SHA1；幂等回执重放不再请求115。目录浏览本身仍按管理员实际操作读取目录列表。
- `AnimeDownloadSnapshot` 中新增值类型 `organization`，保存目标账号编号、凭据版本、UID、目录、策略版本及订阅方案版本；TMDB资料与各来源映射继续保存在同一任务的 `naming`。Cookie继续只在固定内存会话中使用。
- 有命名目标的新任务默认冻结整理计划，不依赖布尔选项。缺少目录2时新任务认领失败并回滚，待管理员补齐；不完整配置仍可先存草稿。没有可靠命名资料时不猜测，保留原有原文件下载能力，页面不提供处理方式选择。
- 修改整理目录2只改变新任务目标。目录1实际账号、凭据版本、UID、CID、路径不变时，共享设置版本变化不再使已有 RSS 基线、认领或恢复失效；这些实际绑定发生变化仍拒绝。启用预览和设置保存继续要求准确 CAS。
- 同 Hash 已有任务始终关联原任务，不因当前目录2被更改或清空而新建任务、改写原方案或重复下载。

## 标准命名

纯计算包 `internal/animeorganize` 只读取任务已保存的文件清单与快照，没有网络 I/O。

```text
整理目录2/
  黑暗召唤师在地下恋爱中 (2026) {tmdb-335790}/
    Season 01/
      黑暗召唤师在地下恋爱中.S01E01.实际字幕组.mkv
      黑暗召唤师在地下恋爱中.S01E01.实际字幕组.zh-Hans.forced.ass
```

视频优先使用真实文件名解析的编号，再按该来源的冻结映射转换。只有唯一视频且文件名没有编号证据时，才采用可信发布标题；多视频、合集、复合编号及 SP 不用普通发布集号覆盖其证据。未映射或 TMDB 未收录的目标保留待核对状态。

视频保留原扩展名及大小写。字幕只与同目录且 basename 唯一对应的视频配对，保留语言、forced、sdh 等允许的后缀；不按单纯集号猜配。其他附件标记为保留原处。清洗非法路径字符、按 UTF-8 字节有界截短；生成后的重复完整目标路径标记冲突，关联字幕跟随受阻，不覆盖。不同字幕组生成不同文件名，可以共存。

所有预览明确 `cloudConflictChecked:false`，本轮只判断计划内部冲突。目标网盘已有同名文件的检查留给实际执行批次，不额外查询115。

## 接口与交互

以下接口均在管理员鉴权后使用严格 DTO：

| 接口 | 行为 |
| --- | --- |
| `PATCH /api/admin/anime/settings/organize-directory` | `{expectedRevision,cid}`；需要 Idempotency-Key；返回 `{id:"anime-settings",revision,settings}` |
| `GET /api/admin/anime/subscriptions/:id/organization-preview` | R-22 已删除：无前端调用，配置弹窗与独立预览使用本地共享计算 |
| `GET /api/admin/anime/jobs/:id/organization-preview` | 本地实际清单及冻结任务方案，不查询当前位置 |

共用目录统一放在选番页右上角“设置”（“我的订阅”左侧）。编辑页只显示轻量目录摘要，并能原页打开同一个设置弹窗，不重建未保存表单；详情“整理计划”也复用此入口。弹窗按需读取本地设置，只有主动选择目录才浏览115，选定后立即保存，不增加总保存按钮。读取成功同步摘要和版本；目录保存结果未知时保留原方法、key、正文、账号及CID，关闭弹窗或切换路由后仍能核对原请求，确认前不允许另选目标。退出登录或身份变化清除前端待确认记录。

详情“整理计划”按需展开，路径预览只在主动点击时生成，失败保留上次结果。成功更新目录后原示例失效，需要重新读取；不把新目录应用到历史任务。目录保存逻辑集中在 `useAnimeStorageSettings`，页面共用 `AnimeStorageSettingsDialog`；嵌套选择器沿用现有原生dialog，维护两级焦点和滚动锁，路由离开后统一释放。

320px 路径竖排自然折行，使用项目现有 Tabler 图标；无处理模式单选项、整理开关或独立“保存整理方式”按钮。执行能力未接入的提示准确保留。
