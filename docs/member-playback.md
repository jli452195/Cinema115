# Emby 个人中心与播放授权

普通用户使用 Emby 账号登录个人中心，邀请码注册直接创建 Emby 账号。没有独立网站用户密码、二次注册、同名关联或接管邀请。管理端使用独立的管理员登录入口。

本地 `emby_profiles` 仅保存 Emby 身份投影，以服务 ID 和用户 ID 的摘要作为归属键；用户名不是身份。每次验证个人中心会话都查询 Emby 状态，已停用、已删除、管理员身份或服务器变更均拒绝访问。密码、Emby 登录令牌不写入数据库或响应。账号改名、密码修改在 Emby 完成。

## 邀请与小号池

邀请类型固定为 `personal`（自备网盘）或 `assigned`（管理员小号池）。服务端存储待遇，邀请限用一次；注册请求不能自行更改待遇。新建用户先应用并读回禁用策略，再设置密码和名称。持久化随机预约名与固定 Emby ID，超时重试不会重复创建或认领同名已有用户。邀请核销、身份投影与播放配置在同一事务提交。

自备网盘注册后可浏览，绑定并验证个人 115 后开通播放。小号池按可用凭据及目录选取未分配账号，一人一个固定分配；数据库唯一索引防止重复分配。无可用账号时保持待分配，后台及管理员检查可继续分配。已分配账号失效或删除时保留绑定、暂停播放，不自动轮换或回退主账号。

管理员在 `/users` 管理邀请及全局媒体库、原文件下载和开关，在 `/emby/users` 管理所有普通 Emby 用户的播放授权。未授权用户拒绝播放，主账号仅用于源文件读取和资源管理。所有用户禁止音视频转码、重新封装、删除、字幕管理及控制其他用户。

## 个人网盘与换号

### 媒体库不同步组

在 `/emby/users` 可将普通用户加入或移出“不同步组”。默认组跟随统一媒体库选择；不同步组保留 Emby 的 `EnableAllFolders` 和 `EnabledFolders`，在 Emby 中单独配置媒体库及分级权限。加入时保留现有权限，移回默认组后重新同步统一媒体库。管理员固定显示在不同步组，不能通过分组接口加入默认组，也不会因此获得新的播放授权。

普通用户的 `skipLibrarySync` 标记随播放记录持久保存。自动同步、手动重试及同步失败时的禁用策略都保留不同步组的媒体库选择；其他播放授权、115 绑定、停用和禁止转码/重新封装继续生效。此分类不会自动开放全部库或主账号。同步统计单独列出不同步人数。

账号配置具有独立编号，配置固定 115 UID，归属键不再作为账号编号。扫码会话固定原账号、来源与版本。重新登录必须使用同一 UID；更换入口明确允许新账号。

新账号验证成功后事务保存待绑定配置，创建并校验独立目录，最后事务切换当前关联并清除旧账号凭据。目录创建结果不明时保留原关联，管理员可核查并填写目录；用户再继续或取消。旧 UID、目录及文件记录保留，不继承到新账号，也不删除云端文件。取消后仅撤销待绑定凭据。池用户可先准备个人网盘，再主动切换来源。

接口：`/api/auth/login` 为 Emby 登录，`/api/auth/admin/login` 为管理登录，`/api/auth/register` 为邀请注册。个人网盘使用 `/api/me/playback` 下的 `qrcode`、`disconnect`、`drive-change` 和 `use-personal`。旧网站用户 CRUD、接管、二次注册和通用绑定写接口已移除。

## 测试环境重建

不迁移旧网站用户。停止后端后，在 backend 目录运行：

```powershell
go run ./cmd/dbtool -data-dir ../data -action reset-portal -output ../data/backups/before-emby-portal.db
```

工具先创建 SQLite 一致性备份，再清空用户投影、旧网站用户、邀请、播放关联、个人网盘配置、个人副本、用户追更订阅和通知。管理员网盘、全局播放设置、媒体资料及共享追更任务保留。原 Emby 账号与云端文件不删除；已有 Emby 用户重新登录后等待管理员授权。备份路径必须尚不存在。

Emby `/Users/New` 不能原子设置权限，源站应限制为仅反代可访问。已发出的 CDN 链接无法立即撤回。

验证：backend 中 `go test ./...`；frontend 中 `npm run build` 和 `node scripts/emby-portal-ui.cjs`。浏览器测试使用模拟 API，不修改真实 Emby/115 数据。
