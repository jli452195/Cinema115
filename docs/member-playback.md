# 个人 Emby 播放

网站用户管理支持单用户删除。先读取 `GET /api/admin/users/:id/cleanup` 预览，提交固定预览摘要、网站用户名和 Emby 处理方式到同路径 POST。网站创建的 Emby 默认一并删除，接管的已有 Emby 默认保留并锁定。没有 Emby 的账号只清理网站数据；注册结果尚未明确的账号必须先核查。不会按用户名选择远端删除目标。

删除先以事务停用网站账号并保存 `deleting` 状态，撤销扫码会话、个人网盘凭据和反代直链缓存，再核验原服务身份及 Emby ID。删除待完成时禁止重新启用、切换来源或修改删除方式，管理员可从原列表重试。远端删除返回丢失时按固定 ID 查询确认；保留账号则写入并读回禁用策略。共享管理员网盘和云端文件不删除，已使用邀请码不恢复，未使用的原账号专属邀请撤销。

完成后事务删除网站登录、个人追更订阅、通知及活动关联，保留共享追更任务；SQLite 版本 28 的 `website_user_cleanup` 保存不含凭据的原身份和处理方式。个人网盘 UID、目录、归属和文件资料继续保留，凭据清空，不自动转给同名新用户。清理记录在网站用户页折叠显示，保留的 Emby 在播放管理中显示锁定状态，不能通过普通播放授权按钮重新开通。即使应用重启，原身份仍被反代拒绝，不会自动使用主账号。已发给客户端的 CDN 链接不能由本地清理追溯撤销。

回归：`node scripts/website-cleanup-ui.cjs` 使用模拟接口覆盖空账号、Emby 保留/删除、失败重试、确认和深色手机布局；后端覆盖事务回滚、身份核验、旧会话失效和共享账号保留。

115 助手集中创建和管理管理员主账号、小号；Emby 用户侧栏只选择现有播放账号，新增小号通过「去 115 账号管理新增小号」进入助手。独立 Emby 用户显示尚未关联网站账号，不显示个人网盘管理。卡片统一展示「播放来源：主账号／管理员小号／本人网盘」，主账号缺失或未登录明确提示，保存凭据不等于已验证播放可用。

管理员点击「关联网站账号」后，预览并确认媒体库、下载和其他权限变化，再选择关联已有网站用户或邀请新用户注册。已有网站用户仅展示未停用、无 Emby 和个人网盘且未开始注册的账号，后端提交时再次校验，禁止覆盖原关联。修改播放来源后须重新预览；关联后应用全局自助用户策略，权限同步完成前暂不可播放。

专属邀请一天有效、一次使用，通过 `/register#invite=...` 分发，链接由管理员自行交给本人。服务端保存固定服务身份、Emby ID 和不含凭据的权限/来源摘要，注册时重新核验；用户、来源或权限变化会拒绝旧邀请。邀请核销、网站用户创建和 Emby 关联在同一 SQLite 事务提交。已有网站用户的关联拒绝覆盖已有 Emby、个人网盘或进行中的注册；数据库按服务身份和 Emby ID 唯一约束，原 Emby 用户不重建，播放记录保留。

接管账号标记 `adopted`，第一版不允许用户修改原 Emby 用户名或密码。管理员授权的 `allowPersonalSwitch` 允许扫码准备本人网盘与专用目录，准备失败保留原播放来源；`POST /api/me/playback/use-personal` 重新校验 UID、凭据和目录后明确切换，失效不回退。自助用户不能选择管理员账号。新增管理员预览/关联接口为 `/api/admin/member-playback/adoption/:embyID`，生成专属邀请和直接关联均要求匹配预览摘要。

SQLite 版本 27 保存专属邀请目标及 Emby 关联唯一索引。测试使用模拟 Emby/115，不接管真实用户或新建真实网盘文件：`node scripts/emby-adoption-ui.cjs`。

播放授权统一在 `/emby/users` 管理，简洁卡片展示账号来源与状态，侧栏修改来源、停用播放、检查同步及确认异常目录。网站账号页只管理网站登录和邀请，并按网站用户 ID 跳转对应播放记录。自助注册设置保留全局媒体库、下载、注册开关及同步统计，不再显示第二份可编辑用户列表。待注册和本地已有的关联不会因 Emby 离线而消失；用户关联使用固定 ID，不按显示名称匹配。

管理页通过 `/api/admin/member-playback/users` 获取本地归属与个人网盘摘要，独立读取 Emby 实时用户；单用户检查同步使用 `/:id/sync`。普通用户不可访问这些管理员接口，网盘凭据不进入目录响应。浏览器回归：`node scripts/emby-user-directory-ui.cjs`。

管理员在「用户管理 → 自助注册设置」开启自助播放，直接从已配置的 Emby 服务读取媒体库并多选允许访问的库。媒体库编号由服务端校验，保存设置会生成权限版本；已有用户在新版本同步并由 Emby 读回确认前保持暂停，失败记录在管理页并可重试。新增媒体库不会自动授予权限。

媒体库设置保存 `ItemId`，写入 Emby 用户策略时通过 `/Library/VirtualFolders` 映射为 `Guid`，不能把数字 `ItemId` 直接写入 `EnabledFolders`。同步读取失败或媒体库缺失时显示失败，不宣告已同步。Emby 用户管理同时读取个人播放来源；个人用户不显示旧的“未绑定默认使用主账号”选择器，统一跳转到个人播放授权管理。

管理员可以单独允许下载原文件，默认关闭。下载仍要求 Emby 条目权限并通过用户当前授权的播放账号取链。音视频转码、重新封装、删除、字幕管理、直播和控制其他用户的权限始终关闭，项目没有转码开关。

普通用户在「我的播放」自定义用户名、设置独立密码注册 Emby，无需扫码，也不会创建网盘配置或目录。用户名默认使用网站用户名，可输入 3–32 位字母、汉字、数字、点、下划线或短横线，首位须为字母或数字，c115_ 为系统保留前缀。注册时用随机内部名称创建账号并持久保存 Emby ID，写入和读回禁用策略后设置密码，再按固定 ID 改为用户选择的名称，最后开放浏览。创建响应丢失只通过内部随机预约名恢复；不会按自定义名称认领已有账号。Emby 创建接口不支持原子设置权限，因此源站必须限制为仅反代可访问。

注册后的改名与改密码分别使用 `/api/me/playback/username` 和 `/password`，请求必须包含账号版本。目标 Emby ID 一律从网站登录身份解析，不接受客户端选择目标。名称大小写重名检查、账号版本校验和串行操作避免重复提交或旧页面覆盖。改名后按原 ID 读回确认；结果不明时保留待确认状态，后台按同一 ID 核实。Emby 账号删除后即使出现同名账号，也不重新绑定。密码不持久化、不写日志，超时后由用户重新提交；不承诺已签发的 Emby 会话立即失效。用户名与密码修改不更改 115 账号、播放来源或目录。

邀请支持「自行绑定 115」（默认）和「朋友使用主账号」两种待遇，每个邀请码仍为一次性且有有效期。待遇保存在服务端，注册核销后从已使用邀请读取并保存到个人播放记录，不能通过注册请求修改。朋友注册 Emby 后无需扫码即可使用可用主账号播放；主账号未配置或失效时保持待播放。管理员可在Emby 用户管理侧栏中选择主账号、现有管理员小号或要求用户自带 115。现有小号需先配置播放目录，不能选择其他用户的个人账号。

用户自带 115 时扫码后才创建个人配置，并在其网盘建立专用秒传目录。绑定账号失效时保留绑定、允许浏览并暂停播放，不回退主账号；恢复同一 UID 凭据后自动恢复播放。目录创建结果不明确时暂停，管理员核查后补填目录编号，避免重复创建。管理员提供账号的用户不能通过个人接口扫码覆盖或清除该账号凭据。Cookie、密码、直链和请求签名不进入日志或个人播放记录。个人文件副本不作为其他用户的秒传片段来源。

保存设置会通知后台同步；权限写入失败、读回不一致时保持禁播并记录错误，之后自动重试。反代在登录、播放、下载和取链时检查网站账号、开通状态、权限版本及个人 115 目录。音视频转码和重新封装始终禁用，没有转码开关。

个人网盘使用明确的 `ownership=member` 和 `ownerUserId` 保存归属。115 助手仅列管理员账号；「Emby 用户管理 → 管理」分别展示当前播放来源与个人网盘 UID、凭据状态和目录。获取二维码只创建临时会话；登录及 UID 校验成功后，以同一 SQLite 事务保存账号凭据和用户关联，事务失败不会留下空账号。

切换到管理员提供的账号后，已有个人网盘作为闲置账号保留，不转为管理员小号。用户可在「我的播放」清除闲置个人凭据，不影响当前播放；UID、目录及网盘文件保留，切回个人来源后只能重新登录原 UID。启动检查只移除所属用户明确、无 UID、凭据、目录及相关引用的空配置；已有身份或引用的记录保留。

接口：用户 `/api/me/playback`；管理员 `/api/admin/member-playback`，媒体库读取 `/libraries`，手动重试 `/sync`，可分配小号 `/accounts`，修改用户播放来源 `/:id/source`。SQLite 结构版本 26 增加网盘归属字段；个人记录分别保存登录、播放状态和来源。当前无生产环境，不做旧模板迁移。

验证：`go test ./...`、`go vet ./...`；前端 `npm run build`、`node scripts/member-playback-ui.cjs`。测试使用模拟 Emby 与 115 服务，不创建真实账号、目录或文件。
