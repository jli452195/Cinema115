## 执行边界

- 只删除任务保存的资源目录 CID，不按名称搜索，不删除共用下载目录、整理目录或其他任务。
- 使用已保存的文件清单和移动成功回执确认全部计划文件已移动；不新增目录扫描、SHA1 比对或成功读回。正常只增加一次 `/rb/delete` 请求。
- 清理前复核本地任务授权、账号、代次、租约和目录身份，先将清理意图保存在原整理操作日志中，再请求回收站接口。
- 部分移动、未知移动回执、同名冲突均不触发删除。未知移动恢复的当前轮只读取结果，下一轮才能执行新清理写入。
- 清理回执丢失记为 `uncertain`；重启遇到已派发清理只做本地收尾，不重发删除、不补扫源目录。已完成的媒体整理保持成功。
- 暂停阻止新清理，保留目录；换号不改用新账号执行旧任务。已完成的历史任务不重新领取或补扫。
- 没有新增配置项、前端交互、数据库迁移或后台循环。
