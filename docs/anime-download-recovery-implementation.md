# 动漫下载：低请求执行与重启恢复（P2-08）

日期：2026-10-20。进度以[任务表](anime-subscription-tasks.md)为准。本项只改后端，按用户要求继续简化下载、整理流程，减少 115 请求。

## 实现

复用 `anime_download_jobs` 中已有的阶段、租约、下次执行时间和观测，以及既有提交日志、目录回执、文件清单。SQLite 保持 v50，不新建表、不增加迁移、不增加独立队列或常驻循环。

原状态追踪器在同一顺序循环内恢复未完成步骤。每轮最多四个 UID，每个 UID 最多一项；排队、提交恢复与状态读取共用本地租约、最小间隔、UID/Hash 协调和已有状态限流冷却。调度每五秒检查本地 SQLite，不表示每五秒请求 115。

| 保存的进度 | 恢复动作 |
| --- | --- |
| queued，未创建目录 | 一次创建许可，成功 CID 直接保存；随后检查同 Hash 任务并单次提交 |
| 目录创建 dispatched/unknown | 只列固定父目录，唯一同名目录恢复；不再创建 |
| submit prepared | 本地重新检查授权，允许后继续一次提交；暂停时不请求 115 |
| submit dispatched/unknown | 只查确切 Hash；归属不明时才补查结果对象，不重提 |
| accepted/downloading | 到期后一次精确状态查询 |
| completed 且已保存结果 ID，尚未收集文件 | 直接收集任务目录，跳过重复状态查询 |
| 文件清单已保存或工作流已结束 | 不领取、不定位文件、不请求 115 |

成功提交回执保存为 `confirmed`，观测 `kind=accepted`，表示明确的接受回执；未知回执后来查询匹配使用 `kind=matched`。两者均可进入状态追踪，不混淆下载完成与文件收集完成。

正常提交后不立即 GET，首次状态检查至少两分钟后执行。等待任务通常五分钟检查，下载中两分钟检查并有稳定错峰；恢复未知结果至少五分钟，连续读取失败按既有退避逐步延长，最多三十分钟。已明确拒绝不再查询；未知提交或目录补查后仍缺失/冲突转待处理，不盲目反复扫描或重新写入。

精确状态接口首次省略目标 CID 时，成功提交回执可以证明当时的写入目标；仍核对确切 Hash、已知结果 ID 和明确返回的 CID。文件收集始终只访问已保存的专属任务目录，越界结果不能进入完成状态。

P2-09 补充：整体暂停使用状态遮罩及租约失效，保留确认代次/基线；未提交任务暂停保留为 pending，恢复接续同一任务。目录在途回执保留，移除后完成未知目录恢复即可本地取消未提交意图；已接受任务继续必要只读核对，完成后停止。详见[订阅控制实现](anime-subscription-control-implementation.md)。

## 正常请求量

| 步骤 | 请求 |
| --- | --- |
| 准备/恢复目标与检查换号 | 0 次，纯本地 |
| 设置页重新选择并保存目录 | 复用现有保存检查，每个不同目录 1 次；执行时不再重复 |
| 创建资源子目录 | 1 次 POST，成功后不读回 |
| 提交离线下载 | 1 次同 Hash 检查 + 1 次 POST，成功后不追加确认 GET |
| 等待下载 | 仅到期的未完成任务各 1 次状态查询 |
| 下载完成收集文件 | 直接文件/根目录通常 1 次列表，内层结果目录通常 2 次；只增加必要页及子目录 |
| 完成后再次调度、用户自行二次整理 | 0 次 |

未增加文件 SHA1、逐文件元数据查询、下载正文验证、全盘扫描或完成后位置检查。BT info-hash 仅用于资源幂等，与文件内容校验无关。

## 租约、退出与换号

每次执行最多九十秒，复用两分钟随机租约，无需续期线程。每次 I/O 前本地复核账号、任务代次和租约；创建/提交许可及文件写回事务再次校验。旧 token 不能派发新写入、覆盖清单或释放新执行者的租约。回执同步持久化，取消后只允许至多五秒的本地收尾，运行循环等待当前请求退出。

外部成功而本地写回失败时，派发意图仍已保存。重启后租约到期即恢复，只读取结果，不重发 POST；已保存成功的目录、提交、文件步骤直接跳过。数据库失败向循环拥有者返回，保留原意图供重启恢复，不把故障当成结果不存在。

换号不增加远端检测或自动搬迁。新任务在当前主账号重新选择目录即可；旧任务通过廉价本地账号检查停止，防止把旧 CID 用于新账号。仍保留根目录约定中的固定凭据和目录归属边界，不扫描新网盘、不回退小号，不要求 SHA1 或跨账号协调。

完成是本次执行的历史记录。后续用户改名、移动或删除文件，不触发重新定位、恢复原位置、重新整理或下载。P3 命名整理继续复用现有清单，尚未在本项实现。
