## 多账号与多用户模拟

一主账号、两个目标 UID、三名 Emby 用户，其中两人共用一个目标 UID，并发播放同一文件，然后切换新旧格式重试：

- 每位用户收到自己目标账号的链接；共用 UID 的两位用户仍分别隔离直链缓存。
- 新旧格式切换复用同一用户的缓存，无重复取链。
- 即使命中缓存，撤销其中一人的 Emby 播放权限仍立即阻止新的取链，另一人不受影响。
- 清空一个目标账号凭据后拒绝其用户的新请求，不复用旧缓存、不回退主账号；另一个目标账号继续正常播放。
- 现有分享直取/秒传、池满拒绝、故障切换、停止与重播、下载授权用例分别在新旧格式下执行。

这里验证的是模拟服务行为，不代表真实 CDN 连接数或已签发直链能够撤回。当前 Windows 环境未启用 CGO，`go test -race` 无法运行；已执行普通并发测试及五轮重复验证。
