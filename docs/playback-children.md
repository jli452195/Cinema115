# 播放子账号

管理员在「Emby 用户」卡片点击「管理用户」，在弹窗中开启「播放子账号」并设置名额，默认关闭，范围 0–20，不包含所有者本人。关闭或降低名额只限制新建，不自动移除已有账号。

弹窗集中编辑播放来源、子账号名额和媒体库同步组，点击「保存更改」统一保存。后端先核验全部设置，再一次写入本地配置；播放权限随后同步到 Emby，保存成功不代表同步已完成。配置被其他操作修改时会拒绝覆盖，需关闭弹窗并刷新。保存失败保留输入，关闭未保存的弹窗会提示确认；停用播放需单独确认。「查看子账号」关闭弹窗并筛选该用户的子账号。

所有者先在个人中心扫码并完成个人网盘目录绑定，再在「播放子账号」卡片中明确授权共享、填写新用户名和初始密码。子账号直接创建为独立 Emby 用户，拥有自己的观看记录；不能登录网站、个人中心或使用追更等网站鉴权功能。

子账号只共享所有者已完成绑定的个人网盘，Cookie 不复制到子账号，不进入管理员小号池。所有者自己切换到主网盘或共享小号不会改变子账号来源。换个人网盘时，目录校验和事务切换成功后新请求使用新账号，旧副本不跨 UID 转移。所有者解绑、个人凭据清空或被管理员停用时，子账号的新播放请求被拒绝，绝不回退主网盘。

媒体库沿用管理员现有同步组规则；子账号创建时复制所有者的分级与标签限制，后续由管理员在 Emby 管理。所有者不能授予管理身份、媒体库或下载权限。转码、重新封装、媒体删除始终禁止，下载由管理员统一设置控制。

所有者可以暂停/恢复播放、停用/启用登录、重置密码和移除子账号。暂停允许 Emby 浏览；停用同时拒绝登录及经过反代的已识别会话。移除不可恢复共享，保留 Emby 用户、观看记录及永久的已撤销业务身份，释放配额。不能认领已有用户、转移所有者或创建下级子账号。子账号被提升为 Emby 管理员后，停止托管操作，需管理员处理。

创建中、正常和停用子账号占用配额；只有已撤销账号释放名额。创建请求有持久的请求编号及唯一临时用户名。网络响应不确定时用「继续此创建任务」重试；页面刷新后任务仍可见，需要重新输入密码。系统不保存密码，不自动重复创建结果未知的 Emby 用户；无法核验时保留名额并提示管理员核查。

账号数量配额不限制同时播放人数。密码重置不保证旧 Emby 会话立即退出；需要拒绝后续访问时先停用账号。已经发出的 115 原文件直链可能继续有效，不能承诺立即中断已开始的播放。客户端应使用配置的 Emby 反代地址。

后端使用 `playback_child_creations` 持久保存创建进度，`member_playback` 保存永久子账号身份及所有者关联。网站鉴权逐次拒绝 `playbackOnly` 身份；播放通过 `personal_shared` 解析到所有者网盘，校验当前成员状态、Emby 服务身份及所有者状态。所有者与管理员操作保持分离，所有者不能解除管理员的停用。
