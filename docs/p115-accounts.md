# 115 主账号与小号

打开 /helper115（115 网盘 → 115 助手），在顶部创建主账号，在下方添加小号。账号总数最多 20 个，只允许一个主账号。

- 主账号统一负责分享、STRM、Telegram、云下载、整理、目录监控、追更和播放源文件读取。这些功能不再提供账号选择，只设置各自的目录及业务选项。
- 小号仅用于 Emby 用户播放和秒传目标。在 /emby/users 为用户绑定小号；在小号卡片设置秒传目录，根目录须明确填写 0。
- 手动秒传选择目标用户。后端根据用户绑定确定目标小号和目录，源文件由主账号读取，客户端不能指定其他来源或目标。
- 主账号未配置或失效时提示配置，不回退到小号。Emby 用户未绑定时默认使用主账号；已绑定的小号失效时暂停播放并保留绑定，不自动切回主账号。恢复原账号后新播放请求自动恢复，管理员也可更换绑定或主动解除绑定以使用主账号。

每张卡片独立扫码登录或保存 Cookie。Cookie 留空保留原凭据，新 Cookie 校验成功后才替换。配置绑定固定的 115 UID，清空登录信息后仍保留身份；重新登录必须是同一用户。更换实际账号应删除卡片后重新创建，删除配置不会删除网盘文件。

更换主账号后需要重新选择各功能的目录；更换小号后需要重新绑定用户。运行中的任务固定启动时的账号凭据和设置，后续配置变化不会改变已开始的任务。审核重试及恢复继续核对账号和凭据指纹。

账号保存在 DATA_DIR/cinema115.db。p115_accounts.is_primary 区分角色，唯一索引保证只有一个主账号；uid 保存账号身份。Cookie 使用 AES-GCM 加密并绑定配置编号，密钥由 JWT_SECRET 派生。账号列表不返回 Cookie，浏览器不持久存储 Cookie。

普通功能通过 P115Accounts.Primary(expectedID) 获取主账号快照。配置中的 accountId 用于检查目录归属和拒绝过期页面提交，不是可自由选择的小号。用户绑定通过 ValidateSecondary 校验。Get 和 CookieFor 始终按明确编号读取，不做默认回退。

登录和扫码接口继续使用 /api/admin/p115/accounts/:accountID/...。创建账号传 primary: true 创建主账号，省略或 false 创建小号，角色在创建时确定。小号目录浏览使用 /api/admin/p115/accounts/:accountID/paths，普通云下载接口仅允许主账号。

没有生产数据迁移要求，不自动把普通账号提升为主账号，也不自动重新绑定旧功能。
