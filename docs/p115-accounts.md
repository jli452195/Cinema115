# 115 主账号与小号

打开 /helper115（115 网盘 → 115 助手），顶部明确创建主账号，下方维护管理员共享小号。个人网盘不出现在管理员账号列表。

- 主账号统一负责分享、STRM、Telegram、云下载、整理、监控、追更、源文件读取及默认来源播放。普通功能不提供账号选择；主账号缺失不能回退小号。
- 管理员小号用于动态播放池和秒传目标。在 /emby/users 设置用户来源为共享池，不再选择具体小号。在账号卡片独立登录并设置目录，根目录须明确填写 0。
- 共享池按会话稳定分配，按实际 UID 合计容量和 API 速率。故障时有界换至其他 UID；池空、全失效或繁忙不使用主网盘。个人来源和播放子账号不进入公共池。
- 手动秒传选择目标用户，池用户在任务启动时选择并固定目标账号、凭据和目录；写入开始后不跨账号重试。源文件始终由主账号读取。

每张卡片独立扫码登录或保存 Cookie，不按 UID 复制或同步凭据。新凭据与新目录验证成功后事务换号；失败保留原配置。共享池旧租约需在新取链时重新核验，目录、副本、任务不跨 UID 转移。同 UID 重新登录可保留目录。主账号换 UID 会更换内部配置编号，各功能原目录须重新配置；分享转存新任务仍在主账号根目录创建独立临时目录。

长任务固定启动时的凭据及配置；账号更新不使同一任务中途改号。删除账号配置不删除云端文件。Cookie 以 AES-GCM 加密保存，密钥由 JWT_SECRET 派生，列表、日志和池调度记录不含 Cookie。

池设置支持会话容量、候选数、总预算、保守保留时长、冷却和 API 间隔。账号可参与调度、停止新分配或禁用，也可主动重新检查。UID 占用包含准备及残余占用，多配置同 UID 不增加额度。具体默认值和限制见 [动态播放池](dynamic-playback-pool.md)。

没有生产数据迁移要求，不自动提升主账号、不保留旧固定池分配双轨逻辑。数据库变更无需清空用户或个人网盘。
