# 网站用户与权限

管理员在右上角账号菜单进入「用户管理」（`/users`），创建普通用户。第一阶段不开放公开注册。

- 管理员继续使用根目录 `.env` 中的 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 登录。
- 普通用户使用相同登录页，用户名不区分大小写，密码区分大小写。用户名为 3–32 位字母、数字、下划线、点或短横线，首位为字母或数字；密码为 8–128 字节。
- 普通用户只能浏览看板、搜索、影视详情、人物、合集和入库状态。管理配置、Bot 资源搜索、STRM 生成、日志及用户管理接口均要求管理员权限。
- 管理员可以停用、启用账号或重置密码；每次修改会递增凭证版本，旧 JWT 立即失效，重新启用不会恢复旧 JWT。
- 登录凭证有效期为 24 小时。前端初始化、导航及可见页面定期核对身份；后端每次请求检查普通账号是否有效。

数据库升级到版本 8，新增 `website_users`：稳定用户编号、用户名、Argon2id 密码哈希、角色、停用状态、凭证版本和创建时间。密码使用独立随机盐，哈希、盐和版本不通过用户列表或身份接口返回。备份时仍备份完整 SQLite 数据库。

浏览接口独立挂载于 `/api/catalog`；普通用户获得入库状态及季集编号，不获取 Emby 服务器地址、媒体路径或原始条目编号。已有 `/api/admin` 路径仅供管理员使用。公开播放接口继续沿用原有播放策略。

登录限流为单实例每分钟最多 30 次尝试；密码哈希最多同时进行两次，以控制 NAS 内存占用。

详情页追更按钮、「我的追更」、管理员追更处理及 Telegram 申请通知已接入，见 [影视追更](follows.md)。入库自动完成和站内通知将在后续步骤接入。
