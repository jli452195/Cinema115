# 用户身份

已统一为 Emby 账号登录个人中心，不再提供独立网站注册、网站密码或关联接管。详见 [Emby 个人中心与播放授权](member-playback.md)。

用户登录入口为 `/login`，使用已有 Emby 账号；卡片下方的“管理入口”通向独立的 `/admin/login`，只验证后台管理员账号。邀请码注册仍位于 `/register`，创建的是 Emby 账号，完成后返回用户登录页。

未登录访问业务页面时，会按页面用途进入相应登录入口，登录成功后返回原页面；普通用户仍不能进入管理页面。主动退出时返回对应身份的登录页。

登录凭证有效期为 7 天，在到期前 24 小时内通过现有登录状态校验静默续期，最长从首次密码登录起保持 30 天。已过期的凭证不能续期，需要重新输入密码；浏览器不保存密码。

同一浏览器的标签页同步登录与退出。续期先经过服务端验证，不重置同一用户的订阅编辑和命名模板；旧请求返回的登录失效结果不会清除后来保存的新凭证。网络超时、Emby 暂时不可用时保留登录凭证，本次受保护操作仍须校验通过；确认账号已删除、停用或登录已撤销时才要求重新登录。
