# 已有副本取链授权与灰度验证

## 行为

PickCode 正式播放在完成 Emby 权限检查、用户设备准入和目标账号预占后，允许将目标登录有效性检查延后到已验证文件取链。请求固定账号配置、UID、凭据版本和目录，成功响应同时核对文件 ID、SHA1、大小与直链；核验成功后才允许事务提交会话。没有有效取链证据的延迟授权不能提交。

- 本地可信资料和副本命中：直接向目标账号取链，不查询主账号，不额外读取播放目录。115 未返回 SHA1 时仍按原规则补精确核验。
- 可信资料命中而副本未知：先在固定目标 UID 搜索，命中后核验取链。
- 未知资料：带 SHA1 的 redirect115 可优先查询固定目标账号，正式播放命中且身份核验通过后跳过主账号及保存目录检查；明确未命中再核验源文件，写入前检查保存目录，不信任外部 SHA1 建立来源关联。文件准备与下载保持原授权检查。详见 [redirect115 验证记录](redirect115-target-first-validation.md)。
- 确认没有可用副本、需要秒传：先完成实时目标目录检查，再准备上传、保存意图和写入。二次校验继续使用已接受片段、合格已知副本及按需主账号来源。
- 直链缓存命中（含等待另一个请求生成的直链）：本请求必须实时核验目标凭据和目录，不能继承另一个请求的授权对象。
- 下载和后台任务不进入此优化；主账号原文件直取保留原检查。
- 文件可读不代表配置目录可写，不据此刷新池的完整目录健康状态，也不清除并发发生的目录故障。
- 超时、限流、凭据错误、身份冲突不能视为文件缺失或触发上传。目标故障沿用有界切换规则，未知写入结果不跨 UID 重试。

继续使用现有 SQLite 资料、来源、片段与副本表；本次不引入重复 SHA1 库或改变长期资料身份。

## 自动验证

在 `backend` 目录运行：

```powershell
go test ./...
go test ./internal/httpapi -run 'TestPickCodeReuseCanaryPoolHTTP|TestPoolProtocolNegotiationRedirectAndStop' -count=1 -v
go test ./internal/service -run '^TestFileReuseDeferredAuthorization$' -count=1 -v
```

HTTP 灰度通过真实 loopback 入口运行完整反代、权限和动态池流程，上游使用隔离测试服务。断言首次及再次复用各 1 次目标取链、0 次主账号查询、0 次目录探测、0 次上传；缓存命中实时探测，过期凭据拒绝返回直链。现有设备心跳接替、停播、容量及策略回退回归一起执行。

服务测试覆盖已知副本、仅搜索命中、新秒传、未知资料、缓存失效、目录故障、取链身份冲突、网络错误、取链期间停用、错误凭据、取消、下载和后台任务。

## 真实 115 只读灰度

可选测试默认跳过，显式指定实例根目录才运行：

```powershell
$env:CINEMA115_REUSE_CANARY_ROOT = 'D:/code/Cinema115'
go test ./internal/service -run '^TestPlaybackReuseLiveCanary$' -count=1 -v
Remove-Item Env:CINEMA115_REUSE_CANARY_ROOT
```

测试以只读方式打开实例 SQLite，选择已有且身份匹配的管理员小号副本。凭据仅在测试内存使用，资料、授权和状态写入隔离临时测试目录。HTTP 白名单仅允许该小号取链、精确文件核验和配置目录的一条目录读取，禁止上传、全盘扫描、主账号读取和 CDN 文件下载。输出只含分组请求数与耗时。

2026-10-05 实测：

| 路径 | 115 请求 | 耗时 |
| --- | --- | --- |
| 原流程基线 | 目录 1 次 + 取链 1 次 | 728 ms |
| 优化复用 | 取链 1 次 | 215 ms |
| 再次复用 | 取链 1 次 | 227 ms |
| 缓存授权检查 | 目录 1 次 | 107 ms |

全部主账号请求为 0，云端写入为 0。上述为单副本顺序测试，连接预热及上游波动会影响耗时，不代表平均提速比例。该测试验证服务层真实 115 调用；运行中的实例没有替换或重启，也没有把测试 302 视为客户端已完成播放。
