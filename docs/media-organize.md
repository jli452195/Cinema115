# 通用自动整理（第一版）

入口：管理员功能导航 → **自动整理**（`/media/organize`）。同一页面通过“整理规则 / 整理记录 / 命名模板 / 分类规则”切换，公共命名和分类分别保存；未保存修改离开前提示确认。只加载当前标签，切换后停止该页轮询，后台任务继续执行。规则、执行记录和工作循环独立保存，不读写动漫订阅任务、RSS 集数或归档状态。

## 配置与使用

1. 添加规则，选择 NAS / 本地挂载、115 主账号或 CloudDrive2，设置来源与目标目录。可选填写“整理失败目录”，须与来源、目标分开且互不包含；留空时问题文件保留原处。
2. 点击“立即运行”，按当前规则扫描、识别、移动并清理来源，不需要先预览确认。运行时重复提交复用同一次运行；监控暂停时也可以手动执行一次，不会自动开启监控。
3. NAS / 本地挂载分别提供“实时监控”和“定时扫描”开关，互不影响；115 直连与 CD2 仅使用定时轮询。扫描开关、间隔输入和单位紧凑同行显示，手机宽度不足时换行；单位菜单只有秒与分钟，后台统一保存 1 至 86400 秒。关闭定时扫描后仍可编辑间隔。CD2 新规则默认 20 秒，NAS 和 115 新规则默认 5 分钟。启用定时扫描后先扫描一次，之后独立计时，手动或实时扫描不会推迟定时周期。本功能内顺序执行，同一规则到期时仍在运行则合并为一次补扫。
4. 每张整理记录卡片代表一个视频或 STRM，唯一关联的字幕、元数据和图片归入同一任务。点击查看当前任务及附件的来源、目标、结果；失败时可以修正作品或季集，并仅重试当前任务。已成功的文件不会重复移动。视频成功、附件失败显示“部分完成”。
5. 成功后删除来源文件，目标同名文件保留、不覆盖；单个文件失败不阻止其他作品。配置了失败目录时，无法唯一匹配、季集或命名不明、目标冲突及关联附件保留原名与层级移入失败目录。网络超时、临时查询或网盘故障不移入失败目录。

自动监控同时清理来源目录中的无关文件，包括 TXT、ZIP、RAR、7Z、广告文件等；不检查压缩包内是否含字幕。NAS / 本地挂载、115 直连和 CD2 共用独立的“清理未匹配附件”开关，默认开启，等待时间默认 60 秒，范围 0 至 86400 秒，界面可切换秒或分钟。关闭后保留未匹配的字幕和媒体附件，不影响普通无关文件及空目录清理；已匹配视频的字幕和附件始终立即整理。开启时，0 表示关联复核后即可清理。未匹配文件从首次发现起计时，重复扫描、关闭再开启或修改等待时间不重新计时；文件身份或内容发生变化时重新计算。计时持久化保存，不依赖网盘修改时间；到期后的下一轮完整扫描仍无对应视频且无相关临时下载文件时才清理，不保证到秒触发删除。对应视频正在写入时，字幕与附件留待后续扫描；删除前复核中新到的视频和共享附件所属目录，不把归属不明的文件附到其他作品。

三种存储均固定清理来源根目录下的空子目录，从最深层往上收尾，保留来源根目录。原本为空、文件移动后变空和附件清理后变空的目录均参与；没有视频任务或整理部分失败时也复核已发现的目录，目录读取失败不当作空目录。“立即运行”和定时监控执行相同清理；单任务修正和重试不扫描或清理其他文件。本地使用非递归删除，115 移入回收站。不清理目标或失败目录，身份变化与读取失败保留待重试。清理明细保存在原批次，空目录收尾结束后才发布批次完成状态；页面汇总清理文件、空目录和失败数量。

CD2 复用本轮完整扫描的目录树，包含临时、只读和不参与整理的全部直接子项；仅扣除已确认移动、隔离或删除成功的来源项，同目录改名不减少数量。已知仍有内容的目录跳过清理请求，未扫描或读取失败的分支保持未知并实时复核。候选按层级从深到浅处理，同父目录每批最多 20 项，共用一次父目录身份读取和一次删除结果复核；每个候选仍绕过短期缓存完整读取内容，只有确认空目录才使用官方 `DeleteFile` / `DeleteFiles`。不同父目录最多 4 路并行，意图和结果按层合并持久化；子目录确认删除后再释放父目录候选。20 个同父空目录的正常清理路径为 23 次 gRPC 请求，不含扫描及异常核对。批量部分失败逐项保存已确认结果，不重放删除；请求异常后若实时核验确认目录消失，记录该项已删除并保留异常说明，无法核实则不记成功。CD2 官方接口不提供原子的“仅为空时删除”条件，外部客户端在复核后写入的竞争无法完全排除。

NFO、XML、JSON 和常用图片属于媒体附件：元数据须与对应视频同名；图片可同名或带 `-poster`、`-fanart`、`-thumb` 等明确图片角色后缀，随视频重命名。带其他影视名称的附件不会因目录只剩一个作品而跟随移动。仅 `tvshow.nfo`、`movie.nfo`、`season.nfo`（及对应 XML、JSON）、`poster.jpg`、`fanart.jpg` 等固定名称，以及 `.actors`、`extrafanart` 中的图片可按文件夹归属；仍须确定唯一作品和目标目录。已有可能对应的视频但归属有歧义时保留待核对。已关联字幕、字体、常见音轨文件及未支持整理的 ISO 等媒体文件不作为无关文件删除。

公共附件的归属参考完整来源扫描，暂未稳定的视频仍计入判断；执行已保存计划前再次检查附件归属，不继续执行无有效对应视频的附件移动。

默认同时处理 STRM 和普通视频，没有“文件范围”设置。ISO 不处理。STRM 正文保持原样，不请求其中的播放地址；普通视频不转码、不重新封装，规格只取自已有文件名信息。

本地目录必须存在、可访问且不重叠；选择 NAS / 本地挂载时，CD2 等挂载按本地文件系统使用。Docker 中填写容器内路径，例如：

```yaml
volumes:
  - /volume1/media/inbox:/media/inbox
  - /volume1/media/library:/media/library
```

同一文件系统优先使用不覆盖目标的链接后移除来源；不支持时独占创建目标并复制，完成并检查来源未变化后删除来源。跨挂载的大文件需要复制时间。目录内符号链接不跟随，本地文件修改时间不足 30 秒时留待后续扫描。

115 只使用主账号，不提供小号选择；每次处理固定凭据并核验来源和目标目录。主账号更换后需重新配置目录。本地、115 直连、CD2 分别在各自存储入口内整理，不跨入口搬运。

## CloudDrive2 原生整理

先在“服务连接 → CloudDrive2”保存官方 gRPC 地址及 API Token，再为整理规则选择 CD2。CD2 是独立通用存储服务，可访问 Token 授权范围内的不同网盘和账号，不依赖 115 主账号。任务固定连接及其修订；更换连接后须重新选择目录。

CD2 开启定时扫描后按本规则设置的间隔轮询来源目录，20 秒只作为新规则默认值，不订阅 CD2 事件。正在执行时到期的扫描合并，当前任务结束后补扫一次，不堆积错过的轮次；暂停时仍可手动点击“立即运行”。轮询间隔表示检查周期，实际发现和完成时间还受目录刷新、扫描、排队与整理耗时影响。

每个目录完整读取后立即识别、整理视频及已匹配附件，再扫描下一个目录。写入前只复查当前范围的关联文件，不再为每批视频重扫整棵目录树。同批读取可复用短期目录快照，写入后失效并核验结果；互不相关的目录不共用全局写锁。跳过临时下载文件，未归属字幕和媒体附件按本批次冻结的宽限保留；晚到字幕和附件在后续扫描时按成功整理记录补齐。期满仍无对应视频且没有相关临时下载文件时才清理，不按网盘修改时间计时。实际耗时还取决于 CD2、底层网盘和元数据查询。

同一目标目录的多个普通文件自动使用官方 `RenameFiles` 和多来源 `MoveFile` 接口，每批最多 20 项，无需单独开启。批量范围限于当前完整读取的目录，不等待其他目录凑满；零散单文件沿用单文件处理，避免多余批量预检。视频完成并保存后再处理关联字幕及附件。每批共享目录核对与阶段进度保存，直接复用已核验的文件回执。接口部分失败时逐项记录已确认结果，重试只核对未完成项；改名已生效但回执丢失时，可按原名、预期中间名和精确目标恢复。同目标多来源、失败目录恢复和 SHA1 判重按顺序处理，不覆盖已有文件。

115 直连和 CD2 均提供“自动删除相同文件”开关，默认关闭。开启后，仅在预期目标同名冲突时比较双方接口已有的 SHA1，忽略目标大小和时间；相同则删除来源、保留目标，不同或缺失则保留冲突文件，不下载内容计算哈希。删除前保留来源身份与目标归属核验，115 使用本批次固定的主账号凭据并将来源移入回收站，CD2 使用其独立连接。配置失败目录时，冲突文件按既有失败搬运规则保存。CD2 成功记录支持晚到字幕和附件关联；删除这些记录后不再保留相应来源到目标的映射。CD2 清理已完整扫描并复核的 TXT、ZIP 等普通无关文件，以及满足自定义宽限和关联复核条件的孤立字幕、媒体附件，随后收尾空子目录。

## 识别与命名

识别组合文件名和最多两级父目录中的片名、年份、季号及 TMDB ID。优先核对标准片名和原名，必要时有界查询别名/译名；歧义保留人工确认，不用相似度分数直接决定移动。未知类型的显式 TMDB ID 仍需通过片名搜索确定类型。

自动整理及下载文件清单共用文件季集识别：优先读取完整的 `SxxExx`，分辨率（如 `S01E04 - 1080p`）不参与集数范围；真实连集保持起始集命名。无标准季集时复用字幕组发布命名识别，自动整理可用父目录补充缺失季号。分数集、额外编号冲突和不完整编号留待人工修正，不截取前半段后继续整理。RSS 的发布编号、来源正则、合集判断与订阅映射保持独立。

使用公共电影、剧集命名模板；不把 TMDB 总集数作为整理上限。季号和起始集号可修改。启用分类后，按“分类规则”中保存的 YAML 生成子目录；可视化与源码编辑共用同一份规则，依据 TMDB 类型、原始语言、原产地等信息按顺序匹配。关闭分类后直接使用目标目录。规则格式和匹配语义见 [分类规则计划](media-classification-plan.md)。

电影的国家条件读取制作地区，剧集读取原产地。详情缓存使用包含原产地与原始语言的新版本，旧详情在下一次使用该作品时按需更新，后续集数复用缓存；不因上游确实缺少原产地而反复请求或改用制作地区。已移走的历史文件不会因缓存更新自动重新分类。

## 记录与恢复

扫描只判断来源目录当前存在的文件，不保留“已处理文件”跳过标记；以前成功、失败或删过记录都不影响再次整理。成功搬走后来源中已无文件，自然不会重复；文件重新放回来源目录或重新下载后，按当前规则整理。目标同名文件仍不覆盖，来源变化检查保留。正在运行的规则重复提交复用同一次运行，不并行搬运同一任务。115 判重只使用目录接口已有 SHA1，不读取文件内容。

服务重启时未完成任务标为中断，不擅自继续写入；可打开对应任务记录核对并重试，重试范围随批次一起持久保存。115 重试会检查原文件 ID 是否已到目标位置，避免重复移动。来源内容变化时保留来源，要求重新扫描。

失败目录不参与扫描。移动前保存意图，成功后记录当前位置；115 响应超时可按原文件 ID 核对确切目标。进入失败目录的文件仍可在对应任务弹窗中修正作品或季集并重试，无需手动搬回。移动失败会显示原因，临时目录故障会停止本批后续失败搬运，防止连续请求 115。失败搬运随实际整理自动执行，没有独立确认按钮。

规则页管理目录规则、独立监控开关、自定义扫描间隔和立即运行。运行中允许编辑，当前批次保持启动时冻结的配置，后续自动任务使用新配置。暂停取消对应触发方式下尚未开始的自动扫描，正在执行的批次与已排队的手动任务继续完成；调度设置接口不依赖存储在线状态。后端只在本规则真正执行或重试待执行时阻止删除；明确删除尚未执行的规则会同时清理其排队任务和记录，其他规则不因后台任务锁住。请求状态按规则和操作分别管理。

记录页（`/media/organize/history`）显示媒体任务和折叠的清理摘要。卡片按主文件身份归并，不按 TMDB ID 或季集合并，因此不同集和不同版本仍是独立任务。公共海报、目录 NFO 等只随唯一归属处理一次，不生成独立卡片。卡片显示状态、原名、目标文件名、附件数量和时间，每页 20 个任务；没有记录时显示空状态。

记录页统一提供“全部 / 整理中 / 成功 / 待处理”筛选。排队、扫描和执行中属于整理中；主文件与所有附件完成才算成功；部分完成、失败及需要人工修正的任务归待处理，卡片保留具体结果。搜索按作品名称、原文件名、来源和目标路径匹配，在后端对全部已保留记录先筛选、再分页。筛选、搜索与页码写入 URL，刷新和前进后退可恢复；未产生主文件任务的扫描通过运行提示反馈。

持久化复用现有 SQLite，保存规则、批次执行快照和可检索的任务结果，主文件与关联附件保存在同一任务中。旧 `media-organize.enc` 仅在数据库尚未初始化时导入，事务完成后清除旧文件，后续不双写。记录查询和详情读取仅使用本地数据，不请求 115 或 TMDB；规则启停不需要重写全部历史。移除原先 20/50 批数量限制，记录不会因为达到数量上限阻止新的整理。

可删除单条、勾选当前页记录，或明确清理全部已成功记录；翻页及筛选后清空选择，不能隐藏跨页累选。删除只清理记录及其对应附件和无引用快照，不删除实际文件，不保留墓碑、回收站或已处理标记，也不主动触发扫描。正在处理的批次暂不允许删除，防止运行中的检查点恢复已删记录。删除失败或部分完成记录后失去对应修正重试入口，文件可放回来源目录重新整理。失败目录不属于扫描范围，须先将文件移回来源。删除整理规则也会清理该规则的整理记录，确认弹窗明确提示范围。

单任务修正继续使用独立识别分组，执行仅处理当前任务，成功的视频和同批其他文件不重试。服务重启后已完成结果保留，未完成任务显示中断，可核对后重试。

## 验证

Go 测试覆盖识别、临时本地目录小范围灰度流程、主文件与附件归并、单任务修正重试与重启恢复、STRM 正文、字幕依赖、冲突与来源变化、SQLite 持久化、搜索分页、记录删除、重新放回来源、115 分页、失败重试与凭据固定。`npm run test:media-organize-ui` 验证规则和任务修正；`npm run test:media-organize-history-ui` 验证搜索、筛选、分页及删除边界；`npm run test:organize-workspace-ui` 验证工作区导航、旧地址跳转、未保存保护、轮询停止和移动端布局。浏览器测试使用全模拟接口，无实际 NAS 或 115 写入。
