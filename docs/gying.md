# 观影资源搜索

管理员可从右上角管理菜单进入 `/gying`，填写观影站 HTTPS 地址、用户名和密码。保存操作会先完成站点安全验证和账号登录，成功后才替换原配置。配置、密码和 Cookie 使用 `JWT_SECRET` 派生的密钥加密保存在 `DATA_DIR/gying-config.enc`；接口不会返回密码或 Cookie。

电影或剧集详情页的「观影搜索」仅对管理员显示。后端重新读取该 TMDB 条目，先使用 `originalTitle` 搜索，保留搜索页返回的全部有效条目，不按标题合并季度、OVA 或特别篇。原名没有包含网盘或磁力链接的有效结果时，使用 TMDB 的 IMDb `tt...` 编号再搜索一次。前端不能提交自定义搜索词或覆盖 IMDb 编号。

结果按「全部、电影、剧集、动漫、种子、网盘」分类。每个影视条目保留所有已识别的网盘链接、提取码、资源名、大小、更新时间和磁力链接；相同 URL 与相同提取码去重，不合并不同站点条目。当前版本只提供复制与打开，不接入 115 账号、转存或 STRM。

后端独立实现登录和验证协议，不依赖 PanSou：

1. 访问首页建立初始 Cookie 会话；
2. 遇到浏览器 PoW 验证时读取 `/res/pow`，计算并提交结果；
3. 提交 `/user/login` 登录表单；
4. 访问详情页预热防爬 Cookie；
5. 搜索 `/search` 并读取 `/res/downurl/{type}/{id}` 的资源详情。

详情请求最多同时执行 6 个，同一会话的安全验证串行处理。HTTP 403 或登录页响应会触发一次重新登录，仍失败则停止，不无限重试。单次最多读取前 100 个搜索条目，超过时页面会明确显示截断数量。安全验证计算和 HTTP 响应均设置上限，请求随浏览器关闭弹窗或超时取消。

修改 `JWT_SECRET` 后旧配置无法解密，需要保留原密钥或移走 `gying-config.enc` 后重新配置。删除配置只清除 Cinema115 保存的账号、密码和 Cookie，不修改观影站账号。
