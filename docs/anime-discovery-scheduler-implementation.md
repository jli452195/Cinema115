# RSS 持续发现与有界调度

日期：2026-10-19。对应任务：P2-05。

## 实现范围

为有效的已启用订阅接入后台 RSS 检查，并把可信新发布交给独立的资源元数据核验循环。核验通过后复用 P2-02 的原子资源认领，形成固定主账号与目录的本地下载任务。

本项处理 RSS 发现与本地任务认领。115 提交执行、下载状态、资源子目录创建及文件核对继续由后续下载阶段接入；当前公开 API 的下载能力仍为 false，不能用普通配置保存建立执行基线或自动启用订阅。任务表不将下载闭环提前标为完成。

## 基线与自动选择

- 只有父订阅已启用且有首次启用记录、来源已启用、`runWhenEnabled=true`、存在本来源基线且未标不可用时才领取检查。主源和备用源按相同流程独立运行。
- 执行基线固定下载目标及规则/解析/时间版本。无效基线、解释版本变化、账号或功能目录版本变化阻止自动执行，保留为待重确认，不用当前设置替换原目标。
- T0 和初始已见集合只读，不因定时检查、缓存命中、重启或来源失败而更新。首次确认清单之外的历史不会被自动补入。
- 基线内发布保留为历史；基线外发布必须有可靠发布时间、不早于原 T0、且不晚于本次真实读取时间加五分钟，才能按本来源规则选择。旧帖补录、时间缺失/冲突或可疑未来发布保留待确认。
- 每源独立应用编号范围、最低集数、字幕组与规格条件；重复观察不改写既有 selected/linked、明确排除、过滤或待确认决定。规则调整不会自动恢复这些旧决定。
- 可选发布先持久保存带目标/基线/代次的 `automatic` 选择和原始观测，再有界核验。原帖键不是 Hash；实际种子 info 或受控 Garden 磁力核验成功后才认领资源。同集不同 Hash 继续共存，同 Hash 继续关联原任务，不洗版。

发布观测、逐源决定、成功窗口摘要和下一次检查时间在同一事务提交。派发期间暂停、父/来源版本或代次变化、目标变更、数据库写入失败均不能留下部分新选择。失败不清除原成功窗口或已保存发布。

## 调度与请求预算

| 项目 | 实现 |
| --- | --- |
| 正常 RSS 周期 | 15 分钟加该来源稳定的 0～60 秒错峰 |
| 未安排的有效来源 | 每次最多初始化 32 条，在首分钟内分散，不把所有来源同时设为立即请求 |
| 循环 | RSS 与资源核验各一个工作循环；每轮最多处理 4 项，轮后等待 5 秒 |
| RSS 请求 | 复用三站交互服务及其缓存、站点闸门、请求合并和 Retry-After 冷却；不强制刷新，不读取累计历史 |
| 每条 RSS | 整体 45 秒，至多 3 个未命中缓存请求，单次正文至多 4 MiB、总计 8 MiB、最多 2000 原始行；AniBT/Garden 继续使用各站更小窗口 |
| 来源失败 | 至少 1、5、15、30 分钟退避，后续维持 30 分钟；加错峰并遵守更晚的 Retry-After；成功恢复正常周期 |
| 401/403/风控或字幕组失效 | 来源标不可用，停止自动请求，等待后续显式恢复流程；不会自动试探解封 |
| 资源核验 | 每项至多 45 秒，复用既有 20 秒/4 MiB 种子限制；同轮同目标复用固定凭据会话和目录读取，任务间继续校验账号/设置 |
| 核验失败 | 临时读取失败独立退避；身份/规则/归属不明确转待确认；数据库故障保留可恢复选择并报告错误，不伪装为资源不合格 |

一条来源失败会写回自身健康和退避，继续处理其他来源。RSS 请求慢时，资源核验循环仍可独立处理之前的有效选择。全部停止时取消两个循环及其请求，再等待它们退出；不创建脱离生命周期的协程。

## 并发与恢复

来源检查有随机 token、固定 60 秒期限及父/来源代次校验；网络期限短于领取期限。旧结果不能更新成功时间、决定或释放后来的检查。超期领取可以重新安排读取，这只重做元数据读取，不发送 115 下载请求。

待核验选择同样使用随机 token 和 60 秒期限，重新领取会递增决定 generation。旧核验者不能再认领资源或释放新领取；重启从保存的准确观测恢复，不依赖发布仍在 RSS 窗口内。资源/任务已事务认领但本地回执丢失时，已有来源关联阻止重复核验/认领；迟到错误不能把已存在任务降级或重开。

这些是 RSS 和种子元数据读取的领取机制，不能代替 P2-08 的 115 下载执行租约与恢复。暂停/移除/归档的完整管理操作及界面仍在 P2-09/P2-10。

- 两个循环同时在请求中取消并完整退出、数据库故障取消并等待退出、停用来源不发请求。
- 交互页面读取后调度命中同一蜜柑缓存，不新增上游请求；没有触发累计历史或 115 写操作。
- 实际 v47→v48 升级保留下载任务、来源决定和提交日志，迁移后续失败全部回滚。
