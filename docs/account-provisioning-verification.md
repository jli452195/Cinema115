# 注册与播放子账号创建验证

验证日期：2026-10-05。

## 修复行为

- 注册在改名前事务保存邀请来源及未完成身份，避免发现用户时误归入主网盘。登录启用并读回确认后才消耗邀请、标记完成。
- 子账号登录启用并确认后才标记任务完成；失败保留原任务、永久身份与名额，同一任务可续办。
- 创建响应丢失时只查询随机保留名；策略和改名响应丢失时按原 Emby ID 查询确认。每次确认最多 4 次读取、共用 3 秒预算，可取消；不自动重发创建。
- 创建流程最多等待成员操作锁 5 秒，超时提示繁忙及原任务重试。
- 待启用策略持久保存，重启后续办不再设置已确认的密码，也不重新依赖媒体库模板查询。密码不持久保存。完成后的重复提交不会重写管理员权限。
- 注册完成与网盘健康检查分离。动态池无可用小号时不回退主网盘，页面说明同步修正。

## 自动化验证

- 后端全量 `go test ./... -count=1 -timeout 180s` 通过。
- 新增 `TestProvisioning*` 覆盖创建/权限/改名响应丢失、短暂旧读取、启用失败、重启续办、未确认创建不重发、来源不漂移、待完成登录拒绝、密码不落库、已完成任务不覆盖权限。
- 每轮 8 路同邀请或同子账号任务并发提交，连同启用期间撤销邀请场景重复 20 轮通过；同一身份仅创建一次。
- 原有子账号回归覆盖个人网盘共享、禁止网站登录、配额、停用/撤销、所有者隔离、不认领已有用户、禁止下级共享，以及禁止转码和重新封装。
- 前端类型检查及构建通过。

## 受控灰度范围

本轮为隔离故障注入及浏览器验证，没有连接真实 Emby 创建测试账号，也没有部署或切换服务流量。

- `TestProvisioningHTTPCanary` 使用真实 Emby HTTP 客户端、服务层和临时 SQLite，外部 Emby 由本地 HTTP 服务模拟。创建已提交但返回 502、启用返回 503、同参数续办及重复提交均通过；注册和子账号各创建一次，最终登录可用且转码/重新封装关闭。
- 独立浏览器上下文挂载实际 `RegisterView.vue`、`PlaybackChildren.vue`，仅模拟页面 API。注册失败保留输入，第二次发送相同信息后才显示成功。
- 子账号失败后占用 1/1 名额、用户名锁定、密码清空、保留续办按钮；第二次沿用相同请求 ID 和用户名，成功后展示管理操作。

## 保留的安全边界

若外部创建结果始终无法确认，任务继续保留并提示管理员核查，不自动新建第二个账号。邀请码过期或撤销后不能续办。已完成但最终 HTTP 响应丢失时，应先尝试登录。隔离测试不代表已验证真实 Emby 部署的网络和版本差异；当前 Windows 环境未执行 Go race detector。
