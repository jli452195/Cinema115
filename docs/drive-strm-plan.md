# 115网盘STRM 实施清单

目录 STRM 独立于目录分享、下载整理和动漫订阅。保留主网盘目录层级，在本地生成 STRM；不移动、分享或删除源文件，不识别 TMDB、不重命名媒体。目录树核对会创建临时导出 TXT，并仅清理本功能生成的导出文件。

## 固定约定

- STRM 内容：`{服务地址}/api/drive115/{PickCode}/{文件ID}/{SHA1}/{字节大小}/{URL编码文件名}`。
- 同一次目录列表读取文件字段，不逐文件取详情或计算哈希。不写入 Cookie、登录令牌或 CDN 地址。
- 播放器直接访问此地址时，从当前主账号核对文件身份，复用分享 STRM 的原文件传输逻辑返回媒体；Emby 经 Cinema115 反代时，继续复用已有用户授权与播放来源链路。
- 每个映射绑定主账号配置；换主账号后重新选择来源。每次运行固定凭据和设置。
- 播放地址、视频与元数据后缀、最小视频大小作为本功能独立的全局基础设置，所有目录共用；保存设置不请求 115、不安排扫描。
- 输出只管理自身创建的文件，不覆盖无关文件，不跟随云端删除。明确同一文件改名或移动时，新输出成功后清理旧输出及空目录，不保护已管理文件的手动修改；本地手动删文件后可完整扫描补齐。
- 所有映射共享主账号的一路生活事件读取；事件查询不清空、不确认、不删除上游记录。合并受影响目录后读取列表，确认归属和路径，不逐文件查询详情。
- 生活事件用于及时发现，目录树核对缺失路径，全量扫描校验文件资料；三类周期独立可选、均可关闭。默认事件 20 秒、增量核对 24 小时；定期全量默认关闭，保留 30 天周期。不能把只扫描目录根层当作完整增量。

## 验收边界

不改动云端源文件；仅创建并清理本次目录树导出 TXT。多个映射不重复读取生活事件。无变化不改本地 STRM；失败不推断删除。配置换号、分页异常、文件冲突、恶意路径、运行中编辑和服务退出均有明确处理。不修改真实映射配置或清理其他工具的事件记录。

## 使用

1. 打开「115 网盘 → 115网盘STRM」（`/115/drive-strm`），先保存首页基础设置：播放器或 Emby 可访问的 Cinema115 地址、视频后缀、元数据后缀与最小视频大小。
2. 在「监控目录」添加目录，选择主网盘来源及本地 STRM 根目录下的相对输出目录。新增和编辑弹窗只设置名称、来源、输出及自动监控。
3. 保存目录后生成一次；自动监控控制后续事件发现和定期补漏。元数据按填写的后缀原名下载，留空关闭，不受最小视频大小限制。
4. 「检查更新」读取共享生活事件；「完整扫描补齐」批量读取整个子树的文件资料并补回缺失本地文件，暂停监控时也可运行。不支持批量接口的目录保留递归读取。
5. 「停止本次」中止当前扫描和附件下载，并清除该目录的附件待办；删除映射只删除配置、索引和待办，保留网盘和本地文件。
6. 修改基础设置只影响后续任务，进行中的任务保持原设置；已有 STRM 可手动完整扫描更新。首次使用或从开发中的逐目录设置升级后，须先保存一次基础设置。未保存的输入不会被轮询覆盖，也不会用于启动扫描；可以还原修改。
7. 「自动任务」中选择事件检查间隔，在增量/全量页签设置各自开关与周期，切换页签不改变开关。目录监控开关控制是否参与自动任务，暂停不取消已接受的任务。所有周期关闭时，空闲卡片显示「仅手动」。附件限速独立设置，默认所有目录合计每秒最多启动 2 个文件下载，可选 1～10 或关闭。

## 请求与恢复

- 未启用任何映射或关闭事件周期时，后台不请求生活事件；开启后主账号共享一路检查。失败递增退避，实际间隔不短于选择的周期；手动检查不受全局周期关闭限制。
- 无变化时只读取事件头部；有变化合并目录补扫。按目录核对周期导出目录树，比对本地缺失路径，仅补扫受影响的已知目录；新目录回退最近已知祖先。全量扫描按独立周期读取资料，核验同路径内容替换；不依赖目录核对周期，持续生活事件不推迟这两类任务。
- 首次、手动及定期全量扫描使用子目录关系批次和跨层级文件分页，不再逐个读取叶子目录；索引每页读取、每 1000 条以内短事务写入，未变化记录不执行 UPDATE。
- 单次目录列表同时取得文件 ID、PickCode、SHA1、大小和名称；生成视频 STRM 不请求下载地址。
- 附件逐页持久入队，同目录视频 STRM 写完后独立下载，不阻塞其他目录生成 STRM。未变化的附件在取链前跳过；所有目录共享一路下载与启动限速，不因慢文件积累突发额度。
- 扫描与附件失败分别按 1 分钟、5 分钟、30 分钟、24 小时退避。附件失败只重试该文件，不触发目录重扫；再次发现相同待办保留原周期、设置与退避。手动完整扫描可立即重试扫描，附件仍保留自己的退避。
- 附件待办只保存文件身份、设置和不可逆凭据标记，不保存 Cookie 或下载地址；重启直接继续附件，无需重新列目录。改账号凭据后旧任务不会改用新凭据，重新扫描取得新来源快照后再接受新任务。
- 修改名称不请求115或排队扫描；恢复监控优先目录树核对，首次生成和需要修复的失败扫描仍完整读取。生活事件到来时，同目录正在下载的单个附件先完成，避免反复取消取链；随后继续已排队扫描。
- 输出归属和事件游标存入 SQLite；重复扫描不改写相同内容，保留无关文件；本功能管理的文件允许覆盖手动修改。
- 目录树不包含文件 ID、大小及哈希，无法发现同路径替换或执行最小大小过滤；此类资料由生活事件或完整扫描更新。每日核对是减少响应体及资料处理，导出自身有固定请求开销，小目录不保证比批量完整扫描更少请求。
- 导出任务 ID 与原账号配置独立持久化，不随映射删除而丢失。115 导出不可取消，未完成的任务稍后清理；停止、重启或删除映射后，仍仅按原配置清理其导出。主账号更换后不跨账号清理旧文件。

## 当前边界

- 已核实实际生活事件接口的只读行为；没有穷举验证所有上传工具及改名、复制、恢复操作的事件覆盖，因此提供目录核对、全量核验与手动补齐。关闭定期核对后，遗漏变更及本地删除须通过手动完整扫描修复。
- 云端同一文件改名、移动后，新索引与旧输出清理记录同事务保存；确认新文件存在、旧路径未被其他文件接管后删除旧文件，只逐层移除空父目录，保留映射根。新输出缺失时保留旧文件并独立退避；已管理输出允许覆盖和清理手动修改，不读取两份文件的完整内容作清理比对。云端删除仍不自动删除本地文件。输出目录之间禁止重叠，避免相互覆盖。
- 原生 `drive115` STRM 可独立直接播放：GET/HEAD 复用统一路径解析器，主账号核对文件 ID、大小与 SHA1 后由 NAS 读取原文件，返回 200/206/416，保留 Range、If-Range 和媒体响应头。取链和读流使用同一固定 UA，复用分享 STRM 的传输逻辑；视频流量经过 NAS，不转码或重封装，不需要开启 Emby 反代。反代播放仍遵守原有 Emby 用户授权与账号来源规则。
- 原文件直链按主账号配置、凭据与文件身份保存 5 分钟内存缓存，不因播放器 UA 不同重复取链。30 秒预算只约束取链，不限制整片传输时长；客户端结束读取会取消上游请求。媒体响应开始后不拼接 JSON 错误；上游在响应前失败会清除该链接供下次重播重新取链，客户端中断不清缓存。
- 初版真实灰度覆盖一个小目录；随后增加 289 个子目录、4598 个文件的批量资料读取验证，未执行完整媒体库生成。独立播放已对实际《圣魔之血》STRM 验证 HEAD 200、首尾 Range 206，以及开头和约 20 分钟处音视频数据读取；未覆盖完整影片播放及所有播放器。
