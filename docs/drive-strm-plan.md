# 115 目录 STRM 实施清单

目录 STRM 独立于目录分享、下载整理和动漫订阅。只读主网盘，保留目录层级，在本地生成 STRM；不移动、分享或删除云文件，不识别 TMDB、不重命名媒体。

## 固定约定

- STRM 内容：`{服务地址}/api/drive115/{PickCode}/{文件ID}/{SHA1}/{字节大小}/{URL编码文件名}`。
- 同一次目录列表读取文件字段，不逐文件取详情或计算哈希。不写入 Cookie、登录令牌或 CDN 地址。
- Emby 经 Cinema115 反代授权后识别此声明，复用现有原文件播放链路，不开放匿名公共取链。
- 每个映射绑定主账号配置；换主账号后重新选择来源。每次运行固定凭据和设置。
- 输出只管理自身创建的文件，不覆盖无关文件，不同步删除；本地手动删文件后可完整扫描补齐。
- 所有映射共享主账号的一路生活事件读取；事件查询不清空、不确认、不删除上游记录。合并受影响目录后读取列表，确认归属和路径，不逐文件查询详情。
- 生活事件用于及时发现，低频完整扫描用于补漏；不能把只扫描目录根层当作完整增量。

## 验收边界

云文件零写入。多个映射不重复读取生活事件。无变化不改本地 STRM；失败不推断删除。配置换号、分页异常、文件冲突、恶意路径、运行中编辑和服务退出均有明确处理。不修改线上配置或清理其他工具的事件记录。

## 使用

1. 打开「115 网盘 → 目录 STRM」（`/115/drive-strm`），新增映射。
2. 选择主网盘来源目录，指定本地 STRM 根目录下的相对输出目录，填写 Emby 可访问的 Cinema115 服务地址。
3. 按需开启字幕、NFO、图片下载。保存后生成一次；自动监控控制后续事件发现和每天补漏。
4. 「检查更新」读取共享生活事件；「完整扫描补齐」递归检查来源并补回缺失本地文件，暂停监控时也可运行。
5. 「停止本次」中止当前扫描；删除映射只删除配置与索引，保留网盘和本地文件。

## 请求与恢复

- 未启用任何映射时不请求生活事件；启用后主账号共享约 20 秒一次的检查，失败递增退避至 5 分钟。
- 无变化时只读取事件头部；有变化合并目录补扫。每天完整扫描，补足上游事件覆盖不完整的情况。
- 单次目录列表同时取得文件 ID、PickCode、SHA1、大小和名称；生成视频 STRM 不请求下载地址。
- 附件在视频 STRM 写完后下载；未变化的附件不重复下载。扫描失败按 1 分钟、5 分钟、30 分钟、24 小时退避；手动完整扫描可立即重试。
- 输出归属和事件游标存入 SQLite；重复扫描不改写相同内容，保护无关文件和手动修改后的输出。

- 真实灰度覆盖一个小目录，未对用户完整媒体库执行批量扫描或播放验收。
