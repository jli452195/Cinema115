## 交付范围

从 `/anime` 的篇章详情点击“选择资源并配置订阅”，进入 `/anime/new?bangumiId=…`。详情切换关联篇章后使用当前篇章 ID，不沿用最初打开的作品。保存回执提供“继续编辑”，进入 `/anime/subscriptions/:id/edit`；读取本地配置和已保存资料，不依赖外部篇章继续存在。两条路由均复用管理布局及管理员守卫。

本项只创建或修改草稿、暂停配置和预览输入，不开放启用、下载或整理。没有改动 Go 后端、数据库结构和 SQLite v41，也没有真实订阅、115 目录或离线写入。

## 来源工作台

- 一个主 RSS，最多四个备用 RSS；一次只展开一个来源。手机横向切换来源，避免五个表单连续堆叠。新增备用不复制主来源规则，空白备用可保持草稿，不阻止完整主来源保存为暂停。
- 蜜柑搜索仅按按钮或回车提交；候选不自动认领，选择条目后读取实际字幕组。选定后收起搜索，保留更换入口。搜索失败保留已选配置；保留的旧搜索结果标明原关键词，限流期间禁止重复请求。
- 每个来源分别配置编号范围或人工核对依据、可选的字幕组编号与 Bangumi 篇章集号对应、显式画质、补番下限及首次历史模式。对应基准与下载下限独立；这里没有 TMDB 季集命名，后续在 P3 实现。
- 切换未保存来源的条目或字幕组，清空其范围、编号对应、画质与下限等规则，重新确认；不继承其他字幕组的偏移。已保存条目和字幕组不可直接改绑，更换时明确移除旧来源再添加。移除已选或已保存来源需页面内确认，删除采用 ID 和版本，不依赖“遗漏来源”暗示删除。
- 不完整数字、颠倒范围、不完整对应和超限过滤词在提交前提示，不把已填写的一半范围静默丢弃。包含/排除是文字匹配，每类最多十个词。

## 预览与恢复

预览区分页显示每页 50 条发布，列表高度有界，可查看符合规则、过滤和需人工确认的行；只有服务端允许的行可选。同集不同版本分别显示，最终 Hash 核验仍在后续下载阶段完成。

选择请求提交所有已加载页的选中 ID，翻页不会丢掉其他页选择。继续加载每次增加最多 50 行，遵守各源快照和共享 2000 原始行预算。重新预览复用其他有效来源，并更新响应中全部克隆来源的引用及版本。读取失败保留其他来源；零发布、零匹配、部分历史与来源可见末尾分别说明，不把未加载历史当成缺集或自动补齐。

每个来源独立使用服务端绝对十五分钟期限；页面仅有一个十秒计时器，没有后台读取轮询。修改规则或目录只使受影响的预览失效，旧行显示为“旧选择待核对”，重新预览前禁止修改旧快照。变化或未加载范围中的旧选择单独列出，新增历史不静默扩大原选择。加载或选择回执丢失时，先读取本地快照恢复最新 CAS，再重新预览。

保存的选择只是输入恢复。重新打开编辑页时，旧选中记录标为待核对，不恢复成可执行决定；明确排除记录保留，重新生成首次快照时也不会悄悄勾回。放弃旧记录与对当前资源明确排除分别处理。

## 目录与保存

复用 `P115DirectoryDialog`，固定采用设置接口返回的主账号，不读取账号列表或提供小号选择，也不创建文件夹。此目录为动漫模块共享设置，每条下载资源独立子目录的实际写入仍在 P2。无主账号或目录时可保存草稿；完整主来源与有效目录具备后可保存为暂停。RSS 预览失败不额外阻断暂停保存，服务端仍核验来源资料及目录归属。

配置和目录写入保留不可变正文、原版本及幂等键。网络失败、服务端异常、请求取消或成功回执不完整时，输入锁定，只能重试原请求核对结果；目录结果不明时退出选择弹窗，在原页显示固定目标重试入口，避免继续浏览目录造成误解。已知版本冲突保留输入，不自动提高版本重放；重复篇章提供打开已有配置入口，不自动覆盖。重新读取已有配置会提示替换未保存输入。离页和刷新保护未保存输入、进行中的保存及结果待确认操作。

请求标识使用 `crypto.getRandomValues`，兼容局域网 HTTP 下不存在 `crypto.randomUUID` 的情况。元数据使用已有有界缓存；配置请求不缓存，令牌仅放认证头。令牌、身份或页面生命周期变化取消旧读取并拒绝迟到结果。
