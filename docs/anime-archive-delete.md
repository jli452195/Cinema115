# 归档后继续订阅与删除

归档停止 RSS 调度并保留配置和执行记录，弹窗仍可编辑。普通修改保存后保持归档；新增或重新启用字幕组时，主按钮为“保存并继续订阅”，原保存接口在同一事务内保存来源并切换为已启用。已有来源与整理记录保留，新来源由原 RSS worker 初始化，所有启用来源齐集后沿用自动归档。

暂停、继续、归档和删除放在弹窗公共管理区，各标签都可操作。删除确认与动作在途时锁定配置及其他写入；核对原请求使用原幂等键，刷新与关闭沿用未完成请求保护。

删除通过原 `POST /subscriptions/{id}/remove` 入口清除本地订阅、来源、预览、执行记录及不再共用的资源记录，不操作 115。仍被其他订阅引用的任务和公共站点关联缓存保留。原 worker 执行锁尚未释放时返回 `TASK_BUSY`，提示稍后重试，不为删除增加云端查询。

不保留可浏览的“已移除”状态。SQLite v55 使用同一删除函数一次性清除旧的软移除记录，保留其他订阅与全局设置。仅保留最小请求去重标记，避免旧创建请求重试把已删除订阅重新建回来；删除成功响应丢失仍可核对原请求。

验证覆盖：归档普通编辑与新增字幕组的状态、旧来源保留、任务忙、共享任务、事务回滚、删除回执重放、旧创建请求失效、v54 升级与重复打开、前端深浅主题和手机交互。未执行真实 115 下载或删除。
