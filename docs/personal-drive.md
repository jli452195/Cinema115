# 个人网盘登录与秒传目录

在「我的播放」中选择登录客户端（默认支付宝小程序），同意保存凭据后获取二维码。切换客户端会清除当前二维码，需要重新获取；客户端类型只决定登录凭据所属端，不更改播放请求 UA。

首次登录或换号成功后，网盘保持待绑定状态，不自动创建目录。选择「选择秒传目录」，浏览本人网盘并选择已有文件夹，再点击「确认目录并完成绑定」。也可在目录浏览器中点击「在此新建 Cinema115 并使用」，明确创建并使用专用文件夹。支持手填目录 ID，不允许直接使用根目录作为秒传目录。

绑定完成后，可用「更换秒传目录」选择其他文件夹。新任务使用新目录，已经启动的任务继续使用启动时的目录及凭据，原文件不会移动或删除。

换号时，目录校验及事务提交成功前保留原绑定；取消待绑定网盘会清除待绑定凭据。如果文件夹创建结果不确定，请先浏览网盘并选择已经创建的文件夹，系统不会自动重复创建。当前使用主网盘或管理员共享小号的用户，准备个人网盘完成后仍须主动点击「切换到我的网盘播放」。

个人目录接口位于 `/api/me/playback/directories` 和 `/api/me/playback/directory`，只接受当前用户所属的当前或待绑定账号，并校验配置版本。管理端不能通过这些接口读取或修改个人凭据。
